## 二、核心公式

结算入口是 `js/combat.js` 的 `Combat.resolve(opt)` —— **纯函数，不修改游戏状态**。
护甲耐久的写回统一走 `Combat.applyDurability(res)`，玩家与敌人共用。

```
有效防护值   A = 10L − 10(1 − D/Dmax)          D ≤ 0 或无甲时护甲失效，A = 0
生命伤害     H = (D ≤ 0 或 P ≥ A) ? B : 0.08·B·Kb      二选一，不叠加钝伤
耐久损耗     ΔD = min[D, B(0.035 + 0.009P)·Kd]
完全维修     ΔDmax = (Dmax − D)·Kr,  D'max = D' = Dmax − ΔDmax
修理费       原价 ÷ 原厂耐久 × 缺失耐久 × 0.45，取整到 10，最低 ¥100
```

- `L` 防护等级 1~6；`D` 当前耐久；`Dmax` **当前最大耐久**（含维修后的永久损耗）。
- `B` 子弹固定基础肉伤；`P` 子弹穿透力；`Kb/Kd/Kr` 由护甲材质决定。
- **穿透判定一律用命中前的耐久**：本发的 ΔD 不能反过来影响本发。
- **头部倍率与距离衰减在结算之后乘**（`health = baseHealth × HEAD_MULT × falloff`），
  不进入 B，因此也不会放大本发的磨甲量 ΔD。
- 无甲、护甲失效、穿透成功都造成全额 B；未穿透只造成钝伤。
- 只要命中时身上有甲就磨甲，与穿透结果无关（与旧「完全穿透不磨甲」不同）。

常量集中在 `CFG.COMBAT_MODEL`（`LV_SCALE / WEAR_SPAN / BLUNT_RATIO / DUR_BASE / DUR_PER_PEN`），
材质在 `CFG.MATERIALS`，弹药在 `CFG.AMMO.FLESH`；枪械、敌人、玩家代码里不再写伤害常量。

## 三、材质参数

| 材质 | id | 钝伤 Kb | 耐久损耗 Kd | 耐修 Kr |
|---|---|---|---|---|
| 芳纶纤维 | `aramid` | 1.25 | 0.75 | 0.035 |
| 聚乙烯复合材料 | `pe` | 0.90 | 0.90 | 0.050 |
| 防弹陶瓷 | `ceramic` | 0.55 | 1.35 | 0.090 |
| 装甲钢 | `steel` | 0.75 | 0.70 | 0.015 |

**决策确认**：规范里材质表给了 Kr，装备表又给了每件「耐修」84~97。
本轮按确认结论 —— **维修损耗只由材质 Kr 决定**；装备表的「耐修」(rep) 是 UI 展示值，
不参与任何公式。旧公式 `缺失耐久 × (1−rep/100) × WEAR` 与 `CFG.REPAIR.WEAR` 已移除。

Lv1 布帽 / 帆布 / 皮革等早期装备按芳纶做简化归类，代表其游戏机制中的防护层，
不意味着普通帆布真的具备芳纶防弹性能。

## 七、V1 验收标准（9 条）

`node tools/test-combat-v1.js` 逐条覆盖；`node tools/test-combat-v1-browser.js`
另外验证开发版与离线版都能加载结算模块、公式一致、真实受击链路与详情浮窗的材质显示：

1. 相同输入得到相同结算结果，不存在随机穿透（含运行时连发子弹 B/P 固定）。
2. 未穿透只能产生钝伤，穿透后不再叠加钝伤。
3. 成功穿透造成全额基础肉伤，命中部位倍率另行处理。
4. 本发子弹造成的耐久损耗不影响本发穿透判定。
5. 耐久归零后，下一发子弹可以直接造成全额伤害。
6. 护甲耐久不得低于 0，当前耐久不得超过最大耐久。
7. 维修后的最大耐久不得高于维修前。
8. 玩家和敌人采用相同的弹药与护甲规则（真实 `Player.hurt` / `Enemy.hurt` 对照）。
9. 12 Gauge 暂时使用独立兼容逻辑，不能因新系统部署而失效。

交叉矩阵报告：`node tools/report-combat-v1.js` →
`design/balance/combat-v1/{README.md, combat-v1-matrix.csv, combat-v1-matrix.json}`，
20 件护甲 × 30 种弹药 = 600 组，输出穿透枪数、击杀枪数、护甲消耗与累计钝伤。

## 八、部署后的数值观察（未擅自调平衡）

`A = 10L` 使 I~III 级护甲在全新状态下对 Lv3 及以上弹药基本无法避免穿透
（例如 5.56 Lv3 的 P=33 > Lv3 甲的 A=30，第一发即穿透）；
高等级甲的生存价值主要来自磨到 A 下降之前的钝伤阶段。这是公式与给定弹药表的直接结果，
本轮按规范原样落地，未改动 P 或 `LV_SCALE`。若需要让低级甲也具备挡弹能力，
请另行决定是调 `A` 的系数还是调弹药 P。
