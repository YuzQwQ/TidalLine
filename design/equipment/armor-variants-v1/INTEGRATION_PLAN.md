## 1. 统一重构move与瞄准

当前Player.armorMove读取body.move，并乘入移动速度；准星散布主要由后坐力驱动，没有独立瞄准收束时间。W.windup是扣扳机后的击发延迟，不是瞄准时间，不能拿它代替新系统。

首版建议把“瞄准时间”明确为：停止移动／结束切枪等准备动作后，准星从准备散布收束至该武器稳定散布所需的时间。鼠标朝向即时响应；准备中仍允许射击，只是准星尚未完全收束。不得延迟每一发子弹或改变射速。

- 武器定义weaponAimTime；身体护甲定义aimPenaltyPct，实例和UI都使用同一个来源。
- 实际收束时间 = 武器基础收束时间 ×（1 + 护甲惩罚百分比 / 100）。
- 现有6款身体护甲与新增4款一并纳入。头盔首版不叠加瞄准惩罚；仍通过重量影响总负重。
- 同一接入版本移除speed *= armorMove这条直接护甲减速。负重分档、潜行、冲刺、涉水、治疗中移动等原有规则保留，不能因为“取消护甲减速”而让超重无效。
- 不把move=0.94直接当成瞄准倍率，也不擅自使用1/move换算。旧move仅用于兼容读取与排查，运行计算只用新字段。
- 新的准备散布不低于武器原有稳定下限，不提高最终命中精度；与后坐力散布合成时取更差的约束，避免重复相乘。护甲不改变后坐力上升／衰减、穿透、伤害、射速和换弹时间。
- 移动、冲刺、切枪、闪避对准备进度的重置或退化统一写入状态机；普通受伤是否退化首版建议不新增。近战不进入枪械瞄准逻辑，冷却与真实伤害不变。
- 玩法提示只显示“瞄准准备中”与时间／惩罚，不把它叫扳机延迟。首版AI攻击节奏保留，NPC装备读取新型号定义即可；不把玩家准备时间额外叠到敌人atkCd。

具体转向阈值、移动准备量和各枪基础收束时间必须用测试决定，不能从物品图标或护甲等级自行推断。

## 3. 型号和兼容必须先完成

先新增稳定型号ID，保留旧type+lv指向原款的兼容映射。修正GEAR.def、GEAR.make、EQUIP.armor和存档规范化按等级重建导致丢失变体的问题，再连接拾取、交易、装备、死亡结算、图标、物价构建与Wiki。

旧档资金、库存数量、当前耐久与原款归属不变。护甲的max、重量、价格和新惩罚从型号定义读取，不能混用同级基础款；重复迁移不生成物品或恢复耐久。旧move即便存在于快照中，也不能继续影响移动。

## 4. 实施顺序

1. 型号ID与兼容：在不改战斗数值时验证所有转移与存档路径。
2. 瞄准状态与惩罚：接入全部身体护甲，并在同版本移除直接移速惩罚；确认没有双重处罚。
3. 用原提案8件数值进行定点、移动、撤离与经济测试，记录结果，不靠抬防护等级补轻甲价值。
4. 绘制并检查8张图标，防暴盔先做缩小预览；面罩只影响视觉。
5. 连接货架／掉落、装备清单、Wiki和离线版。保留等级掉率和商店边界，不借机开放IV级购买或特殊效果。
