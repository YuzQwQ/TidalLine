# 当前敌人数值与掉落审计

依据当前多文件版运行代码提取，不修改游戏参数。代码指纹、原始配置和完整物品池见 [snapshot.json](snapshot.json)；每一件物品的首抽概率见 [loot-pools.md](loot-pools.md)；全部敌人坐标见 [spawns.md](spawns.md)。运行 `node tools/report-enemy-balance.js` 可重新提取附表与快照；本文中的解释和汇总需随平衡调整同步复核。

当前共有五种敌人：拾荒者、回响体、潮汐守卫、据点看守、受雇回收员。

**版本差异：**当前 `潮汐线.html` 尚不包含 `Debuff`。五类敌人的基础配置差异只有多文件版新增的 `injuryType` 字段，血量、伤害、装备等基础配置一致。下文伤残规则针对当前多文件版，不代表离线单文件已经同步。

视距通常仍要求无遮挡；视觉敌人2格内忽略朝向。回响体对玩家的近身感知3格，潜行时×0.55变为1.65格；1.2格以内可隔墙感知。对其他敌人有3.2格近距寻敌逻辑。

噪声半径由事件半径×听觉倍率×安静区倍率决定，每0.1秒扫描。视觉敌人在巡逻时对脚步额外×0.6。玩家普通步行噪声5格，因此无安静区时巡逻拾荒者／看守／回收员约3格、守卫1.8格；回响体约8.25格。玩家枪声基础18格，回响体可听约29.7格。

击杀任意敌人在死亡点形成12格半径、30秒的安静区，开始时感知倍率降至0.4，随剩余时长逐渐恢复。该效果同时影响视距、听觉与回响体近距感知。

## 5. 行为与小队

- 拾荒者、回响体、守卫采用旧AI：巡逻、调查、追击。调查3秒；追击8秒后且失去目标时转调查；寻路通常0.5–0.75秒重算。`LOSE_TIME=4`保留在配置中，当前这条状态机没有读取它。
- 拾荒者生命低于30%，即10.2HP时，追击中以`dt×0.9`的每帧概率转巡逻并把当前位置当新驻点；这不是独立撤退寻路状态。
- 看守对玩家先警告1秒，目标位于守卫锚点3格内才正式交战；被打会立即反击。最多离家8格或追击6秒，然后返回／守家；安静10秒后重置。丢失记忆8秒。连续目视下可沿用已完成瞄准，丢失视线后需重新瞄准。
- 回收员看到玩家即交战，记忆8秒。同一个非空`squadId`才能协作；最多选择1名队友，无线电距离10格、间隔1秒。无线电只共享位置快照，不允许隔墙直接开枪。
- 双人回收队每6秒轮换压制／侧翼角色；侧翼角差至少20°。寻找距目标6–9格的可射击位置，搜索半径6格、最大路径8格；规划最多每人1秒一次、每帧最多2次。当前运行地图的3名回收员均没有`squadId`，因此这些小队协作逻辑目前不生效。
- 拾荒者、看守、回收员同属`scav`阵营，互不射击。`scav`、`echo`、`guard`不同阵营之间会寻敌；玩家仍是敌对目标。普通受伤不打断战术AI瞄准／射击／换弹，死亡才清除动作。

**已确认的互斗实现问题：**回响体近战攻击其他敌人时，对传入的临时坐标对象执行`hp -= damage`，没有扣到目标实体。本次独立VM复核：潮汐守卫被回响体近战攻击前后均为72HP。回响体攻击玩家的14点伤害正常。该问题未修改，做阵营生态平衡时需要先考虑。

### 武器与余弹

- 拾荒者的枪以旧字符串形式存尸体，拾取时自动生成30%默认弹匣：Glock 17为5发9mm Lv1，PP-19-01为9发9mm Lv1，MP-155为2发12G Lv1。与敌人生前无限开火无守恒关系。另有10–30发与其装备等级相同的散装弹。
- 看守／回收员尸体存完整枪械状态，枪内余弹和弹药等级等于死亡时实际剩余值，不额外补30%弹药；备用弹也是死亡时剩余，打完就没有。满弹杀死可获得看守最多18发、回收员最多60发，分别分布于枪内和备弹中。
- 所有掉落护甲保留实际剩余耐久；看守／回收员出生就只有60%–90%，战斗还会继续损耗。守卫不掉自己的武器。
- 回收员独立1%额外近战，不占普通物品件数；成功后重型丛林砍刀与廓尔喀弯刀各50%，即每具尸体各0.5%。参考价分别675,000与1,080,000。
- 枪械回收估价固定半价；背包也按装备回收估价处理；护甲按耐久折价；普通物品参考价格与商人实际收购价需区分。
