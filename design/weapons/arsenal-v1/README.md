## 输入与动作

- B 循环切换当前枪的射击模式；局内装备条右键也提供切换入口。HUD显示模式与就绪、射击、泵动、装填状态。
- 半自动和泵动每次按下只触发一发；全自动允许按住；三连发每次按下最多三发，发间隔按RPM。松开鼠标不会取消已开始的一轮三连发，切枪、换弹、闪避、近战、背包、搜刮、轮盘、治疗或死亡会取消未发部分。
- 逐发装填按每发时间结算，已装入的弹药保留。装填途中点击开火，完成当前这一发后停止装填并击发一次；切枪、闪避和死亡直接取消尚未装入的一发。
- Remington 870 每发后自动泵动0.8秒，泵动尚未完成不能开火或装填；切到别枪时暂停该枪的剩余泵动，余量随物品保存，重新装备不能跳过。
- 弹匣式装填完成时统一转入备弹，优先当前优先弹种，随后同口径其他等级补满。短按R装填，长按R选择优先弹种并退弹重装。
- 每个更新帧最多发射一发，低帧率不瞬间补发。正常帧率使用冷却余量补偿避免RPM因取整持续降低。前摇、泵动和装填均不由动画回调结算。

## 后坐力与散布

沿用 R=M+N×H+D×V 的局部坐标系。四种类别分别有基础冲击，再乘型号倍率；V只做准星视觉位移，没有额外伤害或散布。瞄准中心误差每发采样一次，霰弹再独立采样六枚弹丸扩散，不再把动态准星散布重复加到弹丸上。护甲瞄准时间惩罚、命中部位、弹药系数和穿透矩阵保持原规则。

## 物品、交易与掉落

- 12款枪均在军火商出售，满弹匣交付，半价回收；手枪只进副武器槽，其余枪只进主武器槽，仍各占一格。
- 两种新增口径各五级；军火商仍只卖一、二级，每次30发。
- 7.62×39mm：每格60发，单发0.016kg，Lv1–5单价80/180/420/1000/2500。
- .45 ACP：每格90发，单发0.015kg，Lv1–5单价50/110/250/600/1500。
- 新口径堆叠、重量和价格采用已提出的建议首测配置；这几项尚未获得单独确认，集中在JSON方便调整。原三口径堆叠仍为5.56=60、9mm=90、12号=20，单价保持原值。
- 军用物资箱Q和防水补给箱K已有的25%弹药池扩展至五口径；原发数范围保留，新增两口径均10–20发。
- 这两个容器已有的10%装备池增加枪械分支，头盔、护甲、背包、枪械各占该池四分之一。枪械按品质抽取稀有度，无该档枪型时回退普通物品池；掉落枪为空弹匣，备弹仍由独立弹药池提供，不附赠弹药。
- 不增加容器、抽取次数或地图布点，不把枪械放进收集图鉴，不改变NPC独立配置的基础伤害和射击节奏。据点看守明确使用Remington 870，保持其泵动身份；回收员使用M4A1。

## 美术与构建

12张枪械及2张新弹药图，48×48透明PNG，4px安全边，长枪最大40px、手枪最大29px；各口径五级共用一个主体，不烘焙底色。原稿、完整提示词、整理脚本和缩略对照保存在本目录。

重建：

```powershell
node tools/build-economy.js
node tools/prepare-arsenal-art.js
node gen-wiki.js
node build.js --assets-only
```

最后一步使用当前地图快照，不编译编辑器草稿。

## 首测数值观察

参数仍保持需求表，不把通过功能测试等同于实战平衡完成。按Lv2弹药、不计护甲、散布和装填的理论上限，M4A1约246.7伤害/秒、AKM235、FAMAS308.3；FAMAS需要更频繁装填且连续散布增长更快。三把霰弹在六颗全中时分别约204/63.8/255伤害/秒，Remington与MP-155之间的效率差距尤其需要试玩观察，当前保留75与240 RPM的指定值。

新档¥60,000可任选一把手枪或购买Remington，无法直接购买其余主武器；已有初始配装与死亡损失规则沿用原机制。两种新增口径价格只作为首测配置，尚未进行长周期经济或真实玩家命中率校准。
