# 《潮汐线》枪械扩充实施方案 V1.0

## 1. 项目目标

将当前四把通用枪械替换为明确型号，并新增八把枪械，使武器总数达到十二把。

### 现有武器型号明确化

- 原突击步枪 → M4A1
- 原冲锋枪 → PP-19-01 Vityaz（9×19mm）
- 原霰弹枪 → MP-155
- 原手枪 → Glock 17

### 新增武器

- 突击步枪：AKM、FAMAS F1
- 冲锋枪：MP5A3、UMP45
- 霰弹枪：Remington 870、Saiga-12
- 手枪：M1911A1、Beretta 92FS

本次主要完成武器基础性能及必要的射击、装填机制，不增加枪械改装、配件安装、故障或过热系统。

所有武器继续使用现有的单格物品规则。

保留主武器与副武器的装备槽限制，手枪作为副武器，不允许新增武器绕过该限制。

## 2. 弹药兼容

统一使用六种弹药口径：

| 口径 | 适用武器 |
|---|---|
| 5.56×45mm | M4A1、FAMAS F1 |
| 7.62×39mm | AKM |
| 9×19mm | PP-19-01、MP5A3、Glock 17、Beretta 92FS |
| .45 ACP | UMP45、M1911A1 |
| 12 Gauge | MP-155、Remington 870、Saiga-12 |

实际为五种基础口径。如果计入未来可能增加的其他口径，应动态扩展，而不是预留没有内容的弹药类型。

保持现有 1 至 5 级弹药系统。

基本原则：

- 同口径、同等级弹药保持统一的基础伤害和穿透属性。
- 武器型号主要决定射速、精度、操控、弹匣容量和后坐力。
- 不通过枪械价格直接赋予穿透等级。
- 高等级护甲仍需依赖合适的高级弹药。
- 不将高射速武器直接设计为全面优于低射速武器。

12 Gauge 继续复用现有霰弹规则。如果以后增加独头弹或特殊弹丸，需要单独设计弹药行为。

## 4. 射击模式

新增或统一以下射击模式：

- `semi`：半自动，每次有效按下触发一次击发。
- `auto`：全自动，按住射击键按照 RPM 连续击发。
- `burst3`：三连发，单次按下最多连续发射三发。
- `pump`：泵动式，每发完成后等待动作循环结束，之后才能再次击发。

武器射击模式：

| 武器 | 支持模式 |
|---|---|
| M4A1 | semi / auto |
| AKM | semi / auto |
| FAMAS F1 | semi / burst3 / auto |
| PP-19-01 | semi / auto |
| MP5A3 | semi / auto |
| UMP45 | semi / auto |
| MP-155 | semi |
| Remington 870 | pump |
| Saiga-12 | semi |
| Glock 17 | semi |
| M1911A1 | semi |
| Beretta 92FS | semi |

FAMAS F1 的三连发每发仍然使用武器本身的射击间隔。弹匣不足三发时仅发射剩余弹药，射击过程被中断时不得扣除未发射的子弹。

若现有射击系统不支持模式切换，先实现数据字段和基础行为，再逐步接入切换 UI。

## 5. 后坐力设计

继续采用之前确定的鼠标瞄准点局部坐标系。

定义：

- P：玩家位置。
- M：鼠标目标位置。
- D：玩家指向鼠标的单位向量。
- N：与 D 垂直的单位向量。
- H：累计水平后坐力偏移。
- V：累计垂直后坐力偏移。

实际准星：

`R = M + N * H + D * V`

垂直后坐力使准星远离玩家，水平后坐力使准星沿局部垂线左右偏移。

各枪械使用独立倍率：

| 武器 | 垂直倍率 | 水平倍率 |
|---|---:|---:|
| M4A1 | 1.00 | 1.00 |
| AKM | 1.35 | 1.20 |
| FAMAS F1 | 1.10 | 1.25 |
| PP-19-01 | 0.70 | 0.80 |
| MP5A3 | 0.60 | 0.65 |
| UMP45 | 0.95 | 0.90 |
| MP-155 | 1.85 | 1.40 |
| Remington 870 | 2.20 | 1.25 |
| Saiga-12 | 2.10 | 1.75 |
| Glock 17 | 0.75 | 0.80 |
| M1911A1 | 1.20 | 1.00 |
| Beretta 92FS | 0.70 | 0.65 |

这些倍率分别作用于对应武器类别的基础后坐力冲击。不同类别应有独立基准值，不应仅使用统一的冲击量乘倍率。

需要特别注意：纯二维射线射击时，沿 P-M 方向的垂直准星位移本身不改变射击角度。因此 V1 将其作为瞄准视觉反馈，不应擅自通过额外伤害或随机散布模拟其影响。水平后坐力与现有散布负责方向性命中偏差。

保持两个轴的独立积累与恢复。

## 6. 换弹系统

新增两种主要装填方式。

### 弹匣式

适用：突击步枪、冲锋枪、手枪、Saiga-12。

一次换弹动作完成后恢复弹匣容量，具体弹药消耗仍按当前弹药库存规则执行。

### 逐发装填式

适用：MP-155、Remington 870。

每完成一次装填动作恢复一发。

基本要求：

- 弹仓未满时可继续装填。
- 弹仓已满或备用弹药不足时停止装填。
- 射击输入可以在允许的动作边界中断装填。
- 装填中断时保留已经装入的弹药。
- 不允许射击和装填同时修改同一发弹药状态，避免重复扣弹或凭空生成弹药。

Remington 870 还需要泵动动作状态。

建议使用简单状态：

`ready / firing / cycling / reloading`

避免在多把枪上复制独立的射击与装填代码。

## 7. 精度与散布

保留现有散布系统。

每把枪只配置独立的基础散布倍率和连续射击散布增量。

建议：

| 武器 | 基础散布倍率 |
|---|---:|
| M4A1 | 1.00 |
| AKM | 1.10 |
| FAMAS F1 | 1.05 |
| PP-19-01 | 1.05 |
| MP5A3 | 0.80 |
| UMP45 | 1.00 |
| MP-155 | 1.00 |
| Remington 870 | 0.85 |
| Saiga-12 | 1.20 |
| Glock 17 | 0.95 |
| M1911A1 | 0.90 |
| Beretta 92FS | 0.80 |

建议让高射速武器连续射击时更容易累积散布，但不能通过射速倍率重复放大所有散布惩罚。

霰弹枪需要区分瞄准误差与弹丸扩散：

- 准星散布影响射击中心方向。
- 弹丸扩散决定单次射击中各弹丸的分布。
- 两者不要被同一个变量重复计算。

## 8. 武器移动与瞄准

保留当前装备影响瞄准时间的机制。

后续加入武器持械移速时，可以按类别预留配置：

- 手枪：移动惩罚最低。
- 冲锋枪：移动惩罚较低。
- 突击步枪：中等移动惩罚。
- 霰弹枪：根据型号区分，一般略高。

当前阶段如果没有通用持械移速系统，不需要为了新增武器额外开发完整的移动系统。

护甲对瞄准时间的惩罚继续生效，不应被武器数值覆盖。

## 9. 武器贴图规范

保持《潮汐线》现有像素美术风格。

新增武器贴图需要：

- 完整显示枪械轮廓。
- 明确区分枪管、枪托、弹匣与主要机械结构。
- 采用统一观察角度。
- 维持一致的像素密度。
- 不使用现实照片直接缩小替代像素素材。
- 同类型武器尽可能使用一致的画布尺寸和锚点规则。

特别区分以下轮廓：

- AKM：木质护木、弧形弹匣。
- FAMAS F1：无托结构、顶部提把。
- PP-19-01：短枪管、AK 系机匣结构、细长弯曲弹匣。
- MP5A3：圆筒形护木、伸缩枪托。
- UMP45：方正聚合物机匣、折叠枪托。
- Remington 870：长护木、管式弹仓。
- Saiga-12：AK 风格机匣、可拆卸盒式弹匣。
- Glock 17：聚合物枪身、简洁方形套筒。
- M1911A1：金属套筒、单排握把。
- Beretta 92FS：开放式套筒结构、较长枪身。

## 10. 实施顺序

第一阶段：数据层

1. 检查现有枪械数据结构。
2. 明确原有四把枪的型号。
3. 新增八把武器配置。
4. 统一弹药口径引用。
5. 保留旧存档兼容性。

第二阶段：射击与装填

1. 完成统一射击模式接口。
2. 接入半自动、全自动和三连发。
3. 接入泵动动作间隔。
4. 完善逐发装填与弹匣换弹。

第三阶段：手感

1. 应用各枪械的独立散布倍率。
2. 应用水平、垂直后坐力倍率。
3. 调整停火回正。
4. 检查全自动与半自动触发行为。

第四阶段：内容

1. 新增贴图和武器名称。
2. 接入仓库、商人和装备页面。
3. 加入现有战利品与商人商品系统。
4. 检查各枪械价格、弹药消耗和收益平衡。

## 11. 验收要求

完成后应满足：

- 武器总数为 12。
- 每类 3 把。
- PP-19-01 正确使用 9×19mm、30 发、全自动。
- 同口径弹药能够跨武器使用。
- 不同射击模式正确执行。
- 逐发装填可以中断。
- 泵动霰弹枪有独立动作间隔。
- 双轴后坐力使用正确的局部坐标系。
- 现有护甲、弹药等级和命中计算规则正常运行。
- 不改变武器及普通物品的单格设计。
- 新增武器可被仓库、商人、装备和战斗系统正确识别。

**开发原则：优先数据驱动、复用现有机制，不为每把枪单独编写一套射击系统。**
