# 正式战局：射击姿态与瞄准镜头

2026-11-10：把已试玩的靶场规则接入全部正式地图与离线版。

## 操作

| 操作 | 效果 |
|---|---|
| 静止／普通移动 | 腰射 |
| 按住Shift | 潜行肩射，画面1.08× |
| 按住右键 | 主动瞄准，随枪械有效举枪时间逐渐稳定 |
| 短按空格 | 松开时闪避，优先沿移动方向，无移动则沿朝向 |
| 长按空格并移动 | 0.18秒后冲刺，不在松开时补闪避 |

普通瞄具／无镜画面1.15×，光学镜画面统一1.4×。视距独立计算，远程战术镜最大。
镜头向举枪前瞄点聚焦，移动鼠标可在以玩家为中心的有限观察区内移动窗口，允许玩家离屏。
实际可见距离随瞄准推进扩展，从玩家位置做原有射线／视锥判定；墙、关门与不透明物件继续遮挡。
可见范围不会越出有限观察区，镜头与准星同时受地图边界限制。

## 射击与动作

保留七项核心参数；不新增单枪回正参数，不改变射速或弹药伤害。
同属性配件加算与下限先结算，随后应用姿态与移动，伤势散布最后加入。
枪械自身瞄准精度收益线性插值；瞄具adsSpread从55%肩射节点之后渐入，hipSpread到肩射节点前退出。
后坐力收益使用已确认的纵向0.85／横向0.75／连射增长0.70；移动与冲刺惩罚沿用已试玩值。
已经累计的后坐力与散布保留；第一发不会重置已完成的举枪或镜头。

冲刺、闪避、换弹、近战与持续交互中断瞄准。治疗期间不能举枪，闪避会取消治疗。
开包、搜刮、选弹／医疗轮盘会清除右键和空格的暂存输入，释放光标；物品右键仍按原规则处理。
失焦、死亡、结算、返回藏身处和新战局清理暂存状态。自动鼠标锁定不启用。
冲刺／换弹结束后仍按右键则重新举枪；开面板清除按住状态后需要重新按右键。

## 结构与隔离

共享正式逻辑在js/aim.js（ShootingStance）；RangeAim保留为兼容别名。
js/range-aim.js只保留靶场调参面板与读数；靶场临时参数、比较开关不会影响正式默认值。
正式默认值冻结，不进玩家存档。实际配件、弹药和武器的存档行为保持原有规则。
配件描述、物品详情和改枪预览已去掉“仅靶场”的过时标签，操作帮助同步新键位。
弹药型号完整名称保留，格子简称缩短至项目约定的8个半角显示宽度，避免上一轮改名后溢出。
