# 枪械配件首版

本批实现32件配件、12把枪的五槽兼容、局内外即时改装、交易与掉落。配件属于装备／枪械配件，不进入收集图鉴；一件一格、不堆叠、无耐久。当前正式地图快照和布点保持不变。

## 操作与归属

- 仓库枪械详情点击“改装枪械”；局外已装备枪与局内装备条右键“改装”。独立配件可选择“安装到枪械”。
- 局外可选仓库、携带背包及已装备枪械；使用仓库配件，拆下物和余弹返还仓库。
- 局内可选已装备或普通背包中的枪；配件取用与返还均使用普通背包。安全箱不参与改装，需先移出。
- 五个槽分别显示“不支持／原装空槽／已安装”。面板展示原枪、当前、预览数值，不改变枪械图像或品质。
- 面板不暂停世界。射击动作、三连发、击发前摇、装填、泵动、闪避、近战前摇、治疗、搜刮及撤离期间不能提交，会提示具体原因。
- 改装不清除射击冷却、双轴后坐力、模式或泵动余量，不补弹；当前持枪重新进行瞄准准备。

## 安全事务与存档

统一由 js/attachments.js 的 resolve（纯属性计算）、preview（只读完整模拟）与 commit（重新检查后一次提交）处理。UI不直接修改库存。

目标使用具体实例与库存条目引用，不能仅按枪械型号定位。提交模拟取出新配件、返还旧件、退回缩容余弹、格数与负重；任何失败均不改变物品或弹药。替换允许利用新件腾出的格子。已超重时只允许不增加总负重的改装。

扩容上限为 max(base+1, floor(base×1.30))；安装不增加实际弹量。缩容保留队首子弹，队尾按原弹种返回，空间不足则整次取消。所有枪械快照先计算有效容量，再规范化余弹，避免保存、拾取或装备时截断扩容弹匣。

存档沿用原键，保存基础枪ID、配件ID表及既有弹药队列、模式、泵动状态。旧枪为空槽；已知但不兼容的配件返还仓库，迁移允许仓库溢出；未知ID保存在 attachmentRecovery，不参与属性计算。规范化后保存，重复载入不重复返还。安装件随枪转移、丢弃、拾取、出售及现有死亡规则结算。

## 结算规则

同属性百分比先相加，再从原枪定义应用一次。基础散布仅调整稳定下限，最大散布保持原值；双轴冲击独立结算。恢复速度仅作用于H/V回正，不改变恢复延迟、连射散布回落或视觉抖动。霰弹中心散布与六弹丸扩散分开计算。

后坐力、基础散布、连射增长与弹丸扩散最低为原值50%；瞄准、换弹最低60%。护甲瞄准惩罚在配件之后乘算。枪重及回收价包含已装件，伤害、穿透、射速、射程和声学不变。

| 武器 | 可用槽位 |
|---|---|
| M4A1、AKM、PP-19-01、MP5A3、UMP45、Saiga-12 | 全部五槽 |
| FAMAS F1 | 瞄具、握把、枪口、弹匣 |
| MP-155、Remington 870 | 瞄具、枪托、枪口 |
| Glock 17、M1911A1、Beretta 92FS | 瞄具、枪口、弹匣 |

微型反射、全息适配全部瞄具槽；两种光学瞄具仅长枪。普通枪口不适配霰弹枪，霰弹枪使用收束器／扩散器。盒式弹匣按口径通用，管式弹仓禁用弹匣槽。兼容性通过槽位与标签统一计算。

### 掉落

每次抽取独立增加配件分支，保留原弹药、装备分支和容器抽取次数：Q军用物资箱15%，K防水补给箱10%，T工具箱8%，R电子设备柜／e员工储物盒5%；垃圾桶、废纸篓、纸箱、工作服、抽屉、床头柜、帆布挎包、储物柜、旅行箱、文件柜、运动包2%；其余0%。按原容器品质曲线抽档，档内配件等概率；该品质没有配件则回到普通物品池，不强制升档。

## 美术与构建

[32件图标与原稿预览](art/index.html)，[全套预览](art/preview.png)，[配置](attachments.json)。提示词逐件保存在 art/<ID>.json，原稿在 art/sources/，运行小图在 assets/gear/。

透视统一为三分之四前视角、轻微俯视；前侧在左侧前景，后侧退向右侧后景。**握把和弹匣竖直摆放**；瞄具、枪托和枪口前端在左下、后端在右上。正确原图保留，不通过镜像、翻转或旋转修正。使用内置image_gen生成，后处理仅裁透明边、等比缩小、硬透明及调色板整理。48×48透明PNG，至少4px安全边，无稀有度底色；局外详情按需读取原稿。

新增数据：attachments.json → tools/build-attachments.js → js/attachment-data.js。共用改装面板为 js/attachment-ui.js，样式为 assets/ui/attachments.css。运行时预加载小图，原稿仅详情懒加载；没有原稿目录时回退图标。

构建顺序：node tools/build-attachments.js；node tools/prepare-attachment-art.js（需sharp）；node gen-wiki.js；node build.js --assets-only。最后一步使用既有地图快照，不重编地图草稿。图标不属于地图场景素材，无须登记为可放置场景对象。
