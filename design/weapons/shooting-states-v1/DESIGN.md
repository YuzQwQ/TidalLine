# 射击姿态与瞄准方案 V1

定稿日期：2026-11-09。状态：已接入正式战局；靶场保留独立调参面板。
实验入口为 `range.html` 或 `index.html#range`，离线版使用 `潮汐线.html#range`。

## 原型使用

靶场武器列表下方是“射击姿态实验”，收起时显示当前状态、稳定进度、镜头倍率与实际散布。
展开可分别调整普通/光学瞄具画面倍率及各光学瞄具视距；“瞄准散布倍率”已加入单枪七项手感参数。
F2 收起整个调参面板。可取消勾选实验开关与旧手感比较。

姿态规则只保存在当前页面内，可复位、复制 JSON；单枪参数沿用靶场独立调参存储。
正式战局使用已定稿默认值；靶场的启用开关和临时参数不会带入正式地图，玩家库存保持独立。
当前移动瞄准先复用潜行慢速，后续通过实际游玩再评估是否调整。

验收：`node tools/test-range-aim-browser.js` 覆盖普通版与离线版的三种姿态、
瞄具、移动瞄准、空格短长按、后坐力保留、镜头坐标与存档隔离；截图和记录在本目录。

## 枪械参数

保留六项，新增一项，合计七项：

| 字段 | 含义 |
|---|---|
| rpm | 射速，任何姿态均不修正 |
| aimTime | 腰射到完全瞄准的基础时间 |
| recoilVMul | 纵向后坐力倍率 |
| recoilHMul | 横向后坐力倍率 |
| spreadGrowthMul | 每发散布累计量增长倍率 |
| spreadMul | 基础与最大散布倍率 |
| adsPrecisionMul | 完全瞄准时的最终散布倍率 |

不新增单枪 adsControlMul。瞄具倍率属于瞄具配置，不是第八项枪械核心参数。

adsPrecisionMul 初测默认：手枪 0.65、冲锋枪 0.70、突击步枪 0.50、
精确射手步枪 0.30、狙击步枪 0.15、霰弹枪 0.70、轻机枪 0.60。
允许单枪覆盖；以上是测试起点，不是实测平衡结论。

## 操作与姿态

| 操作 | 状态 | 稳定进度目标 a | 镜头目标 |
|---|---|---:|---|
| 默认（静止、行走、冲刺） | 腰射 | 0 | 1.00× |
| 按住 Shift | 潜行、肩射 | 0.55 | 1.08× |
| 按住右键 | 主动瞄准 | 1.00 | 按瞄具决定 |

瞄准优先于肩射，两套收益不叠乘。Shift 不再承担闪避。
稳定进度与镜头过渡分别管理；肩射有可感知的轻微放大，但不会获得完整瞄准倍率。
有效举枪时间 T 由枪械、配件及护甲现有修正决定，避免对瞄具重复计时。
a 按统一速率推进：腰射到完全瞄准需 T，肩射达到稳定需 0.55T，
稳定肩射转完全瞄准需剩余 0.45T。退出建议初测 0.12–0.18 秒。

空格短按闪避，长按并移动冲刺：初测阈值 0.18 秒。
短按在松开时触发；长按进入冲刺后松开只退出冲刺，不能再触发闪避。
判定等待期间照常移动，未进入冲刺不扣冲刺体力。
闪避优先沿移动方向，无方向输入时沿角色朝向。
体力不足或冲刺耗尽不能把本次输入重新解释为另一种动作。

## 性能修正

各项由腰射倍率 1 线性插值到目标：M(a) = 1 + (M_ADS - 1) × a。

| 项目 | 完全瞄准倍率 |
|---|---:|
| 最终散布角 | 单枪 adsPrecisionMul |
| 新产生的纵向后坐冲击 | 0.85 |
| 新产生的横向后坐冲击 | 0.75 |
| 新产生的连射散布累计量 | 0.70 |

不再使用额外的分类后坐力收益表。射速不变。
保留既有后坐力及散布累计量，不清空、不因举枪重新开始回正。
开火不会重新开始整段举枪；射击只继续产生后坐力和散布。

普通移动全速初测：纵向后坐力 ×1.10、横向 ×1.10、连射散布增长 ×1.25、
最终散布 ×1.35。普通移动惩罚随实际速度渐增，避免肩射或瞄准缓慢移动仍承受全额行走惩罚。
冲刺散布为 ×1.80，替代普通移动散布档位，不与 ×1.35 相乘。
冲刺其余后坐惩罚继续通过全局配置统一管理，实测时调整，不增加单枪字段。

瞄准允许慢速移动；冲刺和闪避中断瞄准，结束后仍按住右键则重新举枪。
换枪同样重置举枪。保留既有换弹等动作限制，具体交互在实现时统一处理。

## 镜头与瞄具

视觉过渡使用 smoothstep；性能插值先保持线性。
右键瞄准时镜头平滑向瞄准方向偏移并放大，Shift 肩射仅轻微放大。
从当前镜头状态连续过渡，避免肩射切瞄准或退出时跳变；需同步处理鼠标坐标换算。

| 瞄具 | 画面放大 | 视距参数 |
|---|---:|---:|
| 无镜 / 微型反射 / 全息 / 开放式机瞄 | 1.15× | 1.15 |
| 紧凑棱镜 | 1.40× | 1.45 |
| 低倍率光学 | 1.40× | 1.60 |
| 低倍可变光学 | 1.40× | 1.80 |
| 精密光学 | 1.40× | 2.00 |
| 远程战术 | 1.40× | 2.40 |

画面倍率不等同现实镜具倍率，不增加伤害、穿透、射程或爆头判定范围。
瞄具现有精度收益迁移到瞄准相关计算，避免全姿态散布加成与新 ADS 收益重复叠加。

### 2026-11-10：远处聚焦

进入瞄准时记录举枪前的世界瞄点。光学瞄具随举枪将该处拉至画面中心，
允许玩家离开画面；在地图和有限观察区边界夹取观察窗口，边缘位置不强制居中。
鼠标不动时原瞄点保持不变，不将相机偏移反复累加到目标上。
开镜时隐藏原生光标，以实际世界瞄点绘制准星；鼠标移动按画面倍率换算为相对瞄准位移。
鼠标停止后镜头不再漂移，也不锁定任何敌人。移动玩家时观察窗口照常随玩家平移。
退出瞄准恢复普通视角与光标。移除旧的固定“瞄准前视 px”调参项。
运行 `node tools/test-range-focus-browser.js` 验证原瞄点保留、观测距离、角色离屏、镜头稳定与退出恢复。

### 瞄准中的观察窗口平移

开镜后准星移动会带动放大的观察窗口，窗口只能在以玩家为中心的扩展观察区内平移。
观察区宽高 = 普通画面宽高 × [1.4 + 0.8 × (瞄具视距参数 − 1)]；
窗口本身宽高 = 普通画面宽高 ÷ 当前画面倍率。窗口整体不能越出观察区或地图边界。
高倍率因此有更大的观察区，角色仍可离屏；达到边界时镜头停止，反向移动立即响应。
鼠标位移只更新世界瞄点，镜头追随瞄点，不把镜头位移重复叠加给准星。
面板新增“观察区基准”“倍率观察扩展”“瞄准平移速度”，可现场调整；正式战局已接入，观察范围仍受玩家原点的墙体遮挡限制。

首次开火前的枪械配置检查与每帧举枪检查同步，防止第一次扣扳机重置已完成的瞄准进度。
实际首发测试要求瞄准进度不变、画面倍率不回落、观察镜头不跳动；后坐力仍正常累计。

## 与现有实现衔接

- 替换“移动重置准备、静止自动收准”的旧逻辑；停火只恢复射击累计散布，不自动进入肩射或瞄准。
- 整合 Firearms.kick/recover 中现有移动、冲刺、潜行倍率，不重复惩罚或奖励。
- 计算顺序：枪械与配件基础参数 → 累计射击散布 → 稳定进度修正 → 移动惩罚 → 伤势附加散布。
- 霰弹枪只修正整组射击方向的散布，不用 ADS 压缩 pelletSpread。
- 当前纵向冲击主要是沿瞄准线的视觉位移，不能将降低纵向数值等同于提升实际弹道精度。
- 首轮重点验证腰射近战可用性、Shift 肩射的独立价值、举枪节奏、镜头视野损失及短长按空格的响应。
