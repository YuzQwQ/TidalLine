# 人形敌人装备分配 V1

本次仅扩充出生配枪池。回收员小队、地图出生点、数量、血量、护甲与弹药等级概率、射击节奏均沿用此前版本。没有为回收员分配新的小队 ID，也没有按小队身份提高金色武器概率。

后续已根据实测单独降低[拾荒者瞄准精度](../scav-accuracy-v1/README.md)，本页配枪概率不变。

每名敌人出生时独立抽取一次武器，死亡时掉落手中实际型号及真实余弹，不再重新抽枪。下表为每名对应敌人的配枪概率；武器品质与护甲／弹药等级是独立概念。

## 弹药与掉落

- 枪械使用自身口径、真实容量、射速、后坐力和装填参数，复用玩家的计算入口。
- 出生弹量为实际满弹匣，备用弹仍为拾荒者10–30发、看守12发、回收员30发；弹药等级沿用各自护甲等级抽取规则。
- 半自动／泵动每组单发，全自动每组最多三发；停火与重新瞄准要求保持原值。
- 尸体保留实际枪内余弹、弹药等级和剩余备弹。装备拾取、仓库及存档继续使用现有格式。
- 普通物资、背包、头甲、回收员独立1%收藏近战的掉落规则保持原值。

完整敌人数据见[当前敌人平衡数据](../../balance/enemies-current/README.md)，射击与换弹规则见[共享枪械实现](../shared-firearms-v1/README.md)。

## 试玩与验证

重新开始一局即可在开发版或离线版遇到新配枪。独立入口：[人形敌人测试场景](../human-units-v1/test.html)。其中“拾荒者·短点射”特意固定PP-19-01以观察节奏；正式地图使用本页随机池。

- `node tools/test-human-weapon-pools.js`：6组通过；每类6000次真实生成，共18000次；覆盖权重区间、口径／等级／容量、25种敌人和枪械组合的射击／换弹／尸体／存档，以及地图、小队与其他战斗参数未改动。
- `node tools/test-human-weapon-pools-browser.js`：开发版与离线版均验证全部25种组合的实际抽取、射击、尸体图标、拾取与存档，离线无外部素材请求。
- `node tools/test-human-firearms.js`：8组通过，全部23款枪械×五级弹药与玩家发射结果一致，并覆盖短点射与装填。
- `node tools/test-human-ai.js`：16组通过；`node run-test.js`：416项通过。
- `node tools/test-human-browser.js`：动画、独立场景、尸体与移动端界面通过。

机器结果：[概率与回归](verification.json)、[双入口浏览器](browser-verification.json)。`baseline.json`为本次修改前的配置及地图／源码摘要，供范围回归使用。
