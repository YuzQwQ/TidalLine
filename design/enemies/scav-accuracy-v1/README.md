# 拾荒者瞄准精度调整 V1

拾荒者原先直接瞄准角色圆心，而同心圆命中模型的头部也在圆心。只使用固定角度误差时，近距离的横向误差趋近于零，造成贴身射击几乎必爆头。

本次将拾荒者每组点射的瞄准误差半角从 `0.065rad`（约3.7°）提高到 `0.14rad`（约8°），并加入 `aimErrorMinPx: 14`：瞄准误差半角取 `max(0.14, atan2(14, 距离px))`，再在正负半角内均匀抽取。这是误差范围的下限，不表示每发至少偏离14像素。

误差仍每组抽取一次，组内保持原方向并叠加枪械散布与后坐力。所有拾荒者配枪都使用同一控制器规则。看守与回收员没有配置像素下限，继续使用原有瞄准精度。

伤害、爆头倍率、弹药等级／穿透矩阵、武器分配、护甲、HP、射击节奏及地图／小队配置均沿用调整前规则。没有为玩家子弹增加散布，也没有改变头部判定范围。

## 实际弹道对比

AKS-74U、静止玩家、每个距离每个版本6000次真实首发；使用8个方向及30／60／144FPS混合步进。通过生产代码的瞄准完成阶段、共用枪械发射入口和子弹碰撞统计，共48000发。

| 距离 | 原命中率 | 新命中率 | 原爆头率 | 新爆头率 |
|---|---:|---:|---:|---:|
| 1格 | 100.0% | 72.4% | 97.3% | 23.1% |
| 2格 | 100.0% | 69.3% | 64.8% | 21.6% |
| 4格 | 88.2% | 52.9% | 36.0% | 17.5% |
| 6.25格 | 65.6% | 33.8% | 23.0% | 11.8% |

爆头率的分母是全部首发子弹；命中率包含爆头与身体命中。上述数字是指定武器、静止目标及首发条件下的抽样结果，不代表移动交火、霰弹枪或完整点射的固定概率。近距离仍然可能爆头，四级弹仍会完全穿透三级防护。
