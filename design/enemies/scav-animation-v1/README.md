# 拾荒者动画补齐

保留既有棕色兜帽、旧夹克、面罩、橄榄色裤子／背包和深色靴子，以三个原有静态朝向为参照，用内置imagegen绘制五张动作图集，再整理为15条运行时动画、39帧。

| 动作 | 每方向帧数 | 用途 |
|---|---:|---|
| 行走 | 4 | 巡逻、调查、追击时循环 |
| 抬枪瞄准 | 2 | 开火前的瞄准阶段 |
| 射击 | 2 | 出膛与短促后坐动作 |
| 装填 | 3 | 弹匣／管式装填阶段 |
| 泵动 | 2 | 泵动霰弹枪击发后的循环 |

正面、右侧、背面分别绘制，向左沿用现有渲染器镜像。静止时继续使用原有32px静态图，未重画或覆盖原角色贴图。每帧64×64，身体约26px，头部中线x32、脚底锚点y44；同一条动画只使用一种缩放倍率，不逐帧拉伸。图集等分裁切、alpha硬化、最近邻缩放并限制16色，角色本身没有使用代码绘制。

运行时输出：`assets/anim/scav_<动作>_<s/e/n>.png`。接入点是`js/art.js`中的人形动画预加载列表；AI状态、帧选取和方向镜像复用现有流程，未修改伤害、血量、精度、射击节奏、装备池、地图及回收员小队。
