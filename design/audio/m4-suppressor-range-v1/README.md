# M4A1 消音枪声 · 靶场试听 V1

使用现有shot_rifle原采样做实时处理，不新增／替换WAV，不修改全局音量或AI听觉规则。
仅实际靶场中的M4A1启用；正式地图、其他枪械保持原播放链路。

M4音色已由用户以9半音定稿，专用原声／消音对比及装配快捷按钮已移除，当前面板改为AKM试作。
在靶场选择M4A1并安装紧凑型或重型消音器，实际开火仍保留定稿效果。

实射自动判定att_muzzle08紧凑型与att_muzzle09重型消音器；卸下后立即恢复原声。
首版两件配件使用相同音色，待试听反馈后再决定是否分化。

第二版按“更尖锐、像钉子”的反馈调整：180Hz高通 → 380Hz低架−9dB → 2600Hz高架−4dB → 3400Hz峰值增强+5.5dB（Q1.4）→ 9600Hz低通。
独立声音增益0.64；2ms硬起音，18ms快速收住主体，75ms收尾，130ms淡出，140ms停止音源。
用户最终将pitchSemitones设为9（采样播放速率约1.682×），保持130ms收尾包络和原射速。
保留原型号采样轮换与音高微扰；三连通过音频时钟排程，声音节点播放结束后释放。
缺少采样时合成兜底也应用相同处理。正式场景无法通过强制试听参数开启该效果。

node tools/test-m4-suppressor-range.js保留为兼容测试入口，现由AKM综合测试覆盖M4定稿值、实际开火与旧按钮移除。
第二版减少高频衰减、突出金属起音，同时降低低频拖尾。实际波形读数见验收记录，与AI听觉范围无绑定关系。
既有音频分层、战斗音频浏览器与581项主回归通过。
