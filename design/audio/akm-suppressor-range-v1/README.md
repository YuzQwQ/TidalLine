# AKM 消音枪声 · 靶场试作

M4A1采用用户定稿的9半音设置，移除其专用试听按钮，装配消音器后的实际枪声保留。
本次面板改为AKM，原声来自现有shot_ak47，不新增WAV或替换原稿。
两把枪的处理均继续只在靶场启用，正式地图和其余型号不受影响。

刷新靶场，在“音效试听”点击“装配 AKM＋消音器”，左键正常开火，B切换单发／全自动。
提供“AKM 原声单发／消音单发／原声三连／消音三连”。对比不消耗弹药、不修改真实库存。
紧凑型att_muzzle08与重型att_muzzle09均自动应用，卸下恢复原声。

第二版按“音量偏小，复用M4模板”的反馈调整：AKM直接引用M4定稿模板，统一9半音、gain=0.64与130ms包络、同一套滤波。
保留shot_ak47原采样；额外1.55×（约+3.8dB）响度补偿，只作用于靶场AKM消音声。相同模板在AK原采样上保留能量更少，单独补偿后响度更接近M4。
原型号采样微扰、射速、武器数值及AI听觉规则不变。节点结束后释放，采样缺失时合成音沿用同一处理。
