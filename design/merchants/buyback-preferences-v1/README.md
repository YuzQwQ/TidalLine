# 收集品收购偏好建议首版

状态：已确认并接入运行时。已核对当前物品数据，共九类140件；保持基础价格、稀有度和存档结构不变。完整逐件表为allocation.csv和allocation.json，由build-design.cjs生成，校验每件恰好一位100%偏好买家。

## 规则与人物定位

- 60%低价：非主营的兜底转卖渠道。80%常规：有正常流通渠道。100%偏好：主营、专业鉴定或明确的研究/收藏需求。
- 百分比以现有收集品参考价值计算，不先按装备半价再打折，不调整物品稀有度、基础价值及商店售价。
- 原四位商人都收全部收集品，最低60%；伊莲娜只收文物藏品、神秘学、情报与三件电子白名单，0%表示拒收。偏好互斥，80%与60%可重叠。绑定禁售等规则优先于报价。
- 玛拉扩展到工业材料、生产工艺标样、防护检测、港务物流与资源调配记录；埃德加扩展到电子、军用技术与通信数据；林岑扩展到医学、异常观察与民俗干预研究；维克托负责民用消费、历史文化藏品与收藏转售。
- 伊莲娜接手全部文物藏品与神秘学的专业鉴定；原先100%的买家统一降到80%，其余原四商人的报价保留。林岑仍可按常规价流通神秘学物品，不承担唯一专业鉴定角色。

## 接入约定

1. 仓库各出售入口已统一改为“前往出售”，跳转商人总览，导航不会扣物或加钱；旧直接出售/快捷清仓路径不再成交。仓库总额、装备和物品详情均标为估价，实际所得由商人报价决定，不自动选择最高价。
2. 收购状态应明确区分低价60%、常规80%、偏好100%，不能继续把所有低于1的倍率都标成低价。
3. 同一物品的详情、待售清单和最终结算读取同一报价；金额按每件floor(参考价值×百分比/100)后乘出售数量。物品覆盖先于类别默认。
4. 本表仅分配收集品。枪械、防具、背包、配件、弹药和医疗道具暂保留现有专业商人回收规则及价值口径；若要同样开放跨店兜底，另表设计，避免意外把装备半价改成全价。
5. 未来逐步解锁商人时，原四商人可以提供跨类别兜底，伊莲娜按限定范围收购；解锁新商人的收益首先体现为其独占的100%领域。具体解锁顺序、门槛、信誉和交易额不在本提案中实装。
