# 商品分级解锁方案 v1.0

以下仅为未来货架设计。现有数据引用并不等于本轮上架。商品标价仍引用游戏定义，不改已有物价；Lv1／2系数1，Lv3为0.98，Lv4为0.96。商品折扣总额最多6%，医疗治疗服务不打折，避免破坏其与普通医疗品的收费关系。

限购建议：Lv1／2先不设限；Lv3每成功撤离周期每项2件，Lv4每项1件。弹药以一整堆作为一单位（20／60／90发），记录实际发数，不因拆堆绕过上限。刷新网页、切换地图、失败都不刷新额度。供货与剧情不是自动物品生成能力。

Lv4可为每位商人同时预留1件已定义、已解锁商品；与限购共享额度，领取时付全款，无预付款。下次成功撤离后过期释放，取消仅可退还同周期额度。未来实装需显示预留状态与过期条件。

## 明细模板

```json
{
  "id": "商人ID:商品ID",
  "merchantId": "merchant_armor",
  "trustLevel": 3,
  "reference": {
    "kind": "body",
    "level": 4
  },
  "requiresFlags": [],
  "requiresFeature": null,
  "status": "design_only",
  "price": {
    "source": "current_game_definition",
    "multiplier": 1
  },
  "quota": {
    "quantity": 2,
    "unit": "piece",
    "refresh": "successful_extraction"
  },
  "reservationEligible": false
}
```

医生18件用品的信任分配包含尚无效果的物品。未来新增货架项必须同时满足信任条件和requiresFeature，药效未实现时仅展示“效果待开放”，不提供购买按钮；不能用信任解锁代替药效实现。现有已开放货架的旧档权限建议继承，继承购买权限也不代表药效开放。本轮不改变当前商店。
