## 人物与页面

伊莲娜·莫罗，46岁，私人收藏家、古董鉴赏家，同时经营一间不公开挂牌的私人事务所。她优雅、博学、温和而审慎，有人脉、财力和城府，但不以伤害无辜者牟利。童年父亲的异常失踪促使她研究历史与神秘学；具体真相保留，未与环礁湾灾变成因建立关联。事务所保护身份、告知已知重大风险、履行报酬约定，并可补贴真正需要帮助的委托人。她不亲自战斗。

原始角色提案与全部台词见 `character-proposal.md`。开发边界以本交付和最新实施计划为准；原提案中行动日、周期、任务成长均没有提前实装；立绘已按后续提供的图片接入。原方案的总览、问候、闲置、拆封、接取、完成和秘藏揭示台词已接入共享 MerchantSpeech。

事务所仅有「出售」「私人委托」「个人任务」三个页签，不提供商品购买。个人任务显示未开放及人物故事；信任只显示待开放，没有虚构等级或进度。商人总览五卡同规格：1920宽五列、中等窗口分行且可纵向滚动、移动端单列。

## 收购迁移

文物藏品、神秘学物品全量100%；情报80%；仅即影相机 elec06、微型录像机 elec08、多通道数据记录器 elec13 按60%收购。其余一律拒收，不形成0元交易。原四商人文物／神秘学的100%档降到80%，包括玛拉的工业釉色母版，其余报价不变。

140件收集品唯一100%买家分布：玛拉21、埃德加33、林岑18、维克托32、伊莲娜36。逐件五商人报价在 `../buyback-preferences-v1/allocation.csv`；`tools/build-buyback-data.js` 检查唯一偏好、数量、默认与单品覆盖一致性。伊莲娜直接复用 Sales 的报价、确认令牌和原子出售事务，不引入第二套出售库存。

## 事务与存档

- `sealed → revealed → accepted → claimed`。可交付由仓库实时计算。实例保存独立ID、模板ID、生成时冻结的目标、品质、奖励与状态。未知模板原样保留并禁止结算，不重抽修复。
- 拆封先保存揭示状态再播放CSS信封动画，可跳过；刷新只恢复同一结果。接取立即保存，不加信任。
- 交付框逐项列出匹配的仓库条目，由玩家勾选并填写准确数量；背包、安全箱、已装备物品不参与。待售清单与委托材料选择彼此独立。
- 服务 `Commissions` 提供 ensure/generate、reveal、accept、preview、authorize、commit。复用 `Sales.id` 识别具体条目，确认时校验对象成员资格、数量、指纹、状态与冻结报酬。不能用另一件同ID物品自动替代选中对象。
- 在副本中扣材料、计算腾格、按现有堆叠规则放入全部奖励，再一次提交材料、现金和 claimed。奖励只入仓，不自动装备。一次性令牌防止重复确认；取消或离开页签使UI令牌失效。提交仍重新计算容量。
- 沿用 tideline_save_v1，新增可选 commissionBoard。所有阶段都立即 flush；存储失败恢复原仓库引用、现金和委托状态。旧档缺字段时为 null，首次进入初始化一次。
