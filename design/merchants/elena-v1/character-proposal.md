# 《潮汐线》新增商人部署方案 v1.0

**项目：** TidalLine  
**新增角色：** 伊莲娜·莫罗（Elena Moreau）  
**商人类型：** 收藏家 / 私人事务所经营者  
**建议内部ID：** `elena`  
**开发优先级：** 商人页面 → 委托抽取 → 基础委托 → 后续成长  
**设计状态：** 角色背景与核心玩法方向已确定，具体委托数值待平衡。

---

# 一、核心开发目标

在现有四位商人的基础上新增第五位商人：伊莲娜·莫罗。

她的核心功能不是出售常规装备，而是提供**周期性刷新的私人委托**。

玩家通过完成委托获取现金、高级装备、稀有物品及普通商店难以获得的特殊奖励。

同时，伊莲娜也拥有与其他商人相同的个人任务与信任成长体系，但必须严格区分：

- **商人任务：** 固定剧情、一次性完成、推动角色关系与信任等级。
- **私人委托：** 周期刷新、可重复参与、侧重玩法挑战与高价值奖励。

两套机制可以共享任务目标与奖励结算逻辑，但不能混为同一套任务列表。

## 本次实施范围

优先完成：

1. 伊莲娜角色资料接入。
2. 商人总览页面新增第五位角色。
3. 独立的私人事务所页面。
4. 委托卡片展示及拆封交互。
5. 三档委托品质及信任等级权重配置。
6. 基础寻物委托的接取、交付与奖励结算。
7. 委托状态持久化及存档兼容。
8. 后续时间系统、调查、清除等玩法的接口预留。

暂不实现完整动态地图事件系统，也不修改现有商人的交易功能。

# 二、角色基础设定

## 2.1 基本资料

| 属性 | 内容 |
|---|---|
| 姓名 | 伊莲娜·莫罗 |
| 英文名 | Elena Moreau |
| 年龄 | 46岁 |
| 性别 | 女 |
| 阵营倾向 | 守序善良 |
| 公开职业 | 私人收藏家、古董鉴赏家 |
| 隐藏职业 | 地下私人事务所经营者 |
| 核心特质 | 优雅、博学、善良、谨慎、富有城府 |
| 研究兴趣 | 古董、历史文献、神秘学、异常事件 |
| 核心人物动机 | 调查童年时父亲的异常失踪事件 |

## 2.2 公开身份

伊莲娜是一位在上流社会颇有声望的收藏家。

她长期研究古代文物、历史档案、传统神秘学及艺术品鉴赏，凭借丰富的知识与敏锐的商业判断积累了大量财富。

她与私人收藏家、富豪、学术机构以及古董交易商保持联系。

在公开社交场合，她是一位举止得体、学识渊博、待人温和的贵妇人。

外界很少有人知道，她还有另一项事业。

## 2.3 隐藏身份

伊莲娜经营一家没有公开招牌的地下私人事务所。

事务所接受来自不同社会阶层的私人委托，负责筛选任务、招募执行者、协调资源并支付报酬。

委托人可能来自：

- 普通居民。
- 商人或企业家。
- 私人收藏家。
- 研究机构。
- 政商名流。
- 地下组织。
- 知晓超自然存在的特殊人士。

事务所的执行者以独立雇佣人员为主，而非伊莲娜直接统领的私人军队。

伊莲娜本人不擅长战斗，也不会亲自深入危险区域。

她依靠组织能力、商业信誉、人脉和资金维持事务所运作。

玩家通过可信中间人的介绍，与她建立合作关系。

## 2.4 人物过去

伊莲娜幼年成长于单亲家庭。

她的父亲在一次无法用常规科学解释的事件中失踪。

这一经历促使她长期研究古董、历史及神秘学，希望寻找当年事件的线索。

多年研究让她积累了深厚的鉴赏能力，并逐渐进入古董交易与私人收藏领域。

后来，她为了获取更多调查渠道和人脉，开始组织私人调查与委托业务。

事务所规模逐渐扩大，形成了如今的地下委托网络。

**她经营事务所最初是为了寻找一个人，如今却帮助许多人寻找他们失去的东西。**

父亲失踪事件的具体真相暂不确定，不要擅自将其与环礁湾灾变核心成因直接绑定。

## 2.5 道德原则

伊莲娜属于守序善良阵营。

她并不天真，允许采取必要的灰色手段，但不接受以伤害无辜者为目的的委托。

事务所原则：

1. 保护委托人与执行者身份。
2. 不接受针对无辜者的暗杀及迫害任务。
3. 不故意隐瞒已知重大任务风险。
4. 按约定支付执行者报酬。
5. 尽力履行已经接受的委托。
6. 对确实需要帮助但经济困难的人，可以降低收费或由事务所补贴。
7. 清除敌对武装和异常实体必须具有合理目的，例如保护人员、解除威胁或保障调查安全。

她可以冷静、果断、有城府，但不能塑造成唯利是图的地下犯罪首领。

# 三、NPC立绘及视觉设计

## 3.1 美术风格

沿用现有商人统一画风：

- 传统厚涂油画风格。
- 4:5竖构图。
- 偏写实但不追求照片质感。
- 清晰可见的绘画笔触。
- 低饱和、复古、沉稳的配色。
- 符合架空20世纪90年代工业社会的时代氛围。
- 背景具有适度职业特色。

## 3.2 人物外观

伊莲娜应具有成熟、优雅、知性的贵妇气质。

建议特征：

- 46岁，身形匀称，仪态端庄。
- 深棕或黑色长发，盘成整洁的发髻。
- 面容成熟，神情温和而审慎。
- 深绿色或酒红色复古裙装。
- 配有珍珠耳饰、胸针或精致项链。
- 服装考究但不浮夸。
- 手持旧书、文献或古董怀表。
- 背景为私人藏书室或古董陈列室。
- 眼神中表现出学识、善意和沉静的力量。

避免：

- 夸张魔女造型。
- 现代都市时尚穿搭。
- 过度华丽的宫廷服饰。
- 阴险反派式笑容。
- 赛博朋克元素。
- 过度年轻化。

## 3.3 立绘生成提示词

绘制游戏《潮汐线》中的女性NPC伊莲娜·莫罗，46岁，出身名门的私人收藏家，同时秘密经营地下私人事务所。

她是一位优雅、博学、善良而富有城府的成熟贵妇。

身形匀称，姿态端庄，深棕色长发盘成整洁的发髻，面容成熟自然，眼神温和、聪慧且略带沉思。

穿着符合架空20世纪90年代社会的精致复古服装，以深祖母绿、酒红色或暗棕色为主要色彩，可搭配珍珠耳饰、古典胸针与精致项链。

她可以坐在一张深色木质书桌旁，一只手轻扶一本古老文献，另一只手放在一封带有蜡封的委托函上。

背景是一间温暖而神秘的私人藏书室，摆放着古董、历史书籍、收藏柜、旧式台灯及少量神秘学研究资料。

人物应表现出温柔、克制、善良和理智，而不是阴险狡诈。

传统厚涂油画风格，明显的手绘笔触，低饱和复古色调，柔和的暖色光照，油画质感，4:5竖幅构图，适合游戏NPC立绘。

# 五、私人事务所主页面

与普通商人的购买、出售商店不同，伊莲娜的主要页面用于管理私人委托。

建议页面包含以下模块。

## 5.1 顶部人物区域

显示：

- 伊莲娜立绘。
- 姓名和职业。
- 当前信任等级。
- 一句随机交互台词。
- 当前行动日。
- 下一轮委托刷新时间。

时间系统未实装时，可以显示占位信息或隐藏日期相关控件，不得显示虚构的实时倒计时。

## 5.2 功能页签

建议设置：

**私人委托**

周期性刷新，可重复完成的高价值任务。

**个人任务**

固定剧情任务，推进伊莲娜个人故事与商人信任等级。

未来如有需求，可增加特殊交易页面，但本次不实现常规装备商店。

## 5.3 私人委托页面

主要区域展示当前可查看、已揭示、已接受或正在进行的委托。

每张委托卡片需要显示：

- 委托名称。
- 委托品质。
- 委托类型。
- 委托简介。
- 任务目标。
- 任务奖励。
- 当前状态。
- 到期时间（时间系统完成后）。
- 接受或交付按钮。

# 六、委托品质与抽取规则

## 6.1 委托品质

私人委托分为三档：

| 品质 | 名称 | 定位 |
|---|---|---|
| I | 一般委托 | 普通需求、较低风险、稳定报酬 |
| II | 珍稀委托 | 较高难度、稀有物品及高级装备 |
| III | 秘藏委托 | 高风险、高价值、特殊装备或独特奖励 |

这三档属于委托品质，不等同于现有物品稀有度。

## 6.2 信任权重

建议初始权重：

| 商人信任 | 一般 | 珍稀 | 秘藏 |
|---|---:|---:|---:|
| Lv.1 | 85% | 15% | 0% |
| Lv.2 | 65% | 33% | 2% |
| Lv.3 | 40% | 50% | 10% |
| Lv.4 | 20% | 55% | 25% |

以上权重为初始设计值，后续根据经济平衡调整。

## 6.3 委托揭示

每轮委托刷新后，玩家可以点击按钮：

**「拆封委托」**

触发一个简短的信封拆封动画。

动画内容可包含：

1. 封闭的委托函。
2. 信封开启。
3. 委托品质展示。
4. 委托名称与内容展示。

表现上可以借鉴抽奖揭示的期待感，但不加入付费抽卡、反复刷新或概率付费系统。

**重要：委托必须在刷新周期生成并写入存档。**

点击拆封只负责揭示预先生成的委托，不得每次点击重新抽取。

## 6.4 委托数量

建议每轮提供：

- 2份普通随机委托位置。
- 后续根据信任及平衡决定是否扩充至3份。

品质按对应权重随机生成。

玩家可以决定接受哪些委托，不必全部接受。

委托揭示动画应允许跳过，避免反复操作造成疲劳。

# 七、委托类型设计

私人委托应当保持丰富性，但所有任务必须符合事务所经营逻辑。

## 7.1 寻物委托

**首期优先实现。**

目标：

提交指定名称、类别或稀有度的收集品。

例如：

- 提交指定工业器材。
- 提交指定古董。
- 提交若干电子产品。
- 提交某类医疗收集品。

玩家可以从仓库选择物品进行交付。

完成后扣除相应物品并发放奖励。

## 7.2 回收委托

目标：

进入指定地图，寻找任务物品，并成功带出。

第一阶段可以先预留。

未来需支持：

- 指定地图。
- 指定回收物品。
- 撤离后任务进度结算。
- 任务物品防重复提交。

## 7.3 调查委托

目标：

前往特定区域，调查事件或获得证据。

未来需支持：

- 目标地点。
- 特定交互。
- 调查进度。
- 结果提交。

暂不为此开发复杂的探索工具系统。

## 7.4 清除委托

目标：

清除指定敌对目标。

可包括：

- 掠夺者。
- 危险武装团伙。
- 非人异常实体。
- 特定精英敌人。
- 特定Boss。

不得设计随机暗杀无辜人员的委托。

目标计数应使用现有战斗与击杀事件，而非创建独立战斗逻辑。

如需限定地图、敌人类型或目标身份，应由任务配置定义。

## 7.5 任务组合

未来可允许一份高阶委托包含多个目标，例如：

- 清除指定异常实体。
- 回收其附近的特殊物品。
- 成功撤离。

但第一阶段不必实现所有复合目标。

# 八、委托奖励系统

## 8.1 奖励定位

私人委托的报酬必须具有明确价值。

尤其是材料交付型委托，不能让玩家交出大量高价值战利品后，获得低于普通回收收益的奖励。

建议奖励按照以下原则配置：

**一般委托：**
- 现金。
- 中低级装备。
- 常见补给品。

**珍稀委托：**
- 高级护甲。
- 高级弹药。
- 稀有枪械配件。
- 高品质医疗品。
- 现金补充奖励。

**秘藏委托：**
- 顶级装备。
- VI级护甲。
- 高等级弹药。
- 特殊武器。
- 普通商店无法常规购买的独特物品。
- 少量特殊剧情奖励。

## 8.2 奖励价值平衡

对于需要交付已有收集品的委托，应计算：

`材料机会成本 = 所有材料在当前商人体系中的最高可实现回收价值之和`

建议普通委托的奖励价值通常高于材料最高回收价值。

若委托包含额外地图调查、战斗及撤离风险，应给予进一步补偿。

对于可从维克托购买全部材料的委托，还必须检查全部购入成本，避免出现可无限重复的无风险套利。

## 8.3 奖励选择

建议为珍稀及秘藏委托预留可选奖励结构。

例如完成任务后，玩家可以从以下奖励中选择一项：

- 高级护甲。
- 高级弹药补给。
- 现金报酬。

奖励选项需要在接取前明确展示，避免结算时产生意外。

首期如果现有奖励系统只支持固定奖励，可以先使用固定奖励，后续再增加选择功能。

## 8.4 奖励限制

- 高级奖励不得无限刷取。
- 一份委托只能结算一次。
- 不允许重复提交同一批任务物品。
- 秘藏委托不应成为稳定批量生产VI级护甲的途径。
- 委托奖励可设置周期内数量限制。
- 不随意增加新的物品属性或稀有度。

# 九、时间系统衔接

未来《潮汐线》将拥有统一行动日系统。

该系统用于驱动：

1. 私人委托周期刷新。
2. 商人动态收购价格。
3. 地图异常事件。
4. 其他周期性世界状态。

## 9.1 建议时间规则

采用游戏内行动日，而非真实世界时间。

建议每完成一次正式局内行动，推进一个行动日。

一次行动只允许推进一次日期，不得因重复结算造成多次变化。

## 9.2 委托刷新

建议每7个行动日刷新一批私人委托。

委托刷新状态应写入存档。

玩家未拆封的委托也必须保持固定，不能利用页面刷新重新抽取。

已接受委托的到期规则、刷新时的保留或失效方式，应在正式实现期限系统时统一确定。

**本次不要自行引入真实时间倒计时或未经确认的到期惩罚。**

## 9.3 第一阶段兼容方案

如果项目当前没有全局行动日系统：

- 先完成委托数据结构和拆封交互。
- 使用可控的开发测试入口验证委托生成。
- 不把正式刷新逻辑绑定到现实时间、页面加载次数或商店进入次数。
- 不在正式游戏中暴露可以无限刷委托的测试按钮。
- 待全局行动日系统完成后再启用周期刷新。

# 十、商人信任与个人任务

伊莲娜与其他商人一样，拥有独立信任等级。

信任等级影响：

- 委托品质权重。
- 高级委托开放条件。
- 部分私人客户的委托资格。
- 个人任务剧情。
- 商人态度及台词。

## 10.1 信任等级

建议沿用四级结构：

1. 初识。
2. 熟客。
3. 合作者。
4. 核心关系。

## 10.2 信任获取

主要来源：

- 固定个人任务。
- 完成关键剧情。
- 累计合作。
- 少量私人委托信誉奖励。

私人委托不能无限替代关键剧情任务。

## 10.3 个人任务方向

伊莲娜的个人任务线围绕：

- 童年经历。
- 父亲失踪事件。

# 十二、建议数据结构

优先结合现有项目架构设计，不要求机械照搬以下结构。

```ts
type CommissionTier = 1 | 2 | 3;

type CommissionObjectiveType =
  | "collect"
  | "retrieve"
  | "investigate"
  | "eliminate";

type CommissionStatus =
  | "sealed"
  | "revealed"
  | "accepted"
  | "completed"
  | "claimed"
  | "expired";

interface CommissionDefinition {
  id: string;
  title: string;
  description: string;
  tier: CommissionTier;
  objectives: CommissionObjective[];
  rewards: CommissionReward[];
  requirements?: CommissionRequirements;
}

interface CommissionInstance {
  instanceId: string;
  definitionId: string;
  generatedDay: number;
  expiresDay?: number;
  status: CommissionStatus;
  progress: Record<string, number>;
  claimedRewardId?: string;
}
```

关键要求：

- 委托定义与实际生成的委托实例分离。
- 委托生成结果必须持久化。
- 任务目标和奖励使用现有物品ID。
- 奖励结算保证原子性，避免重复领取。
- 仓库物品交付必须检查真实库存。
- 接受、交付、领取奖励均应具有明确状态转换。
- 存档升级需兼容旧存档。
- 不允许通过反复刷新页面重新生成委托。

# 十五、核心设计原则

**伊莲娜不是第五家常规装备商店。**

她是一位有原则、有城府的私人事务所经营者。

玩家通过事务所接受特殊工作，获得比一般商品交易更有价值的报酬。

私人委托应当带来随机性、期待感和长期重复游玩的动力。

个人任务则负责逐渐揭露她的过去、她的信念，以及那场改变她一生的失踪事件。

她的善良应当体现在实际行动与人物选择中，而不是单纯依靠温柔的台词。

她可以处理危险事务，可以拒绝不合理的要求，也可以利用自己的财富和关系帮助弱者。

**最重要的是：她建立事务所并非为了支配他人，而是为了拥有寻找真相与帮助他人的能力。**
