《潮汐线》商人系统与NPC角色设计方案
用途： 提供给 Agent 用于完善商店系统、商人角色、信任成长、任务结构与 NPC 形象设计。
项目： TidalLine / 潮汐线
版本： v1.0
背景前提：
- 世界为架空历史世界，科技水平接近现实20世纪90年代。
- 环礁湾发生局部灾变，形成长期封锁区。
- 外部世界整体仍正常运转，并非末世。
- 封锁区存在少量人类活动、异常现象与周期性潮汐影响。
- 游戏为PVE 搜打撤，玩家通过进入封锁区搜集物资、撤离、交易、成长。
一、设计目标
请围绕以下目标设计并实现商人系统：
1. 商人不只是商店界面
商人应当是：
- 商品来源
- 任务发布者
- 世界观信息载体
- 角色剧情节点
- 玩家长期养成对象
玩家应当在游戏过程中逐渐：
- 认识商人的职业特点
- 发现他们的真实性格
- 接触他们隐藏的过去
- 提升各自的信任等级
- 解锁更高等级、更稀有的商品
- 参与与商人相关的个人支线剧情
2. 商人要“有城府”
三位商人都不应是单纯的“好人”或“工具人”。
他们可以有：
- 隐瞒
- 自利
- 道德灰度
- 过去的错误
- 各自坚持的原则
但他们仍然要可信、可合作、可持续交易。
即：他们可以复杂，甚至危险，但不能写成纯粹疯子或无逻辑恶人。
3. 信任成长要像塔科夫商人
参考《逃离塔科夫》商人系统，但要适配《潮汐线》的单人 PVE 体验：

每个商人拥有独立的：
- 信任等级
- 信誉值
- 任务线
- 解锁商品池
玩家通过：
- 完成任务
- 达成商人偏好的行为
- 累计交易
- 解锁关键剧情
来提高商人信任，解锁更高级的货物。
二、系统总体规则
1. 三位商人定位
当前只设计三个商店，因此只设置三位核心商人：
1. 护甲商人：出售护甲、头盔、背包、防护装备
2. 军火商人：出售武器、弹药、枪械配件、改装服务
3. 医生：出售医疗品、损伤处理品、针剂、异常处理药物
2. 信任系统结构
每个商人拥有以下成长维度：
（1）信任等级
建议分为 4级：
- Lv.1 初识
- Lv.2 熟客
- Lv.3 合作者
- Lv.4 核心关系
（2）信誉值
每位商人有独立信誉值，例如 0~100 或分阶段累计值。
提升信任等级时，需要同时满足：
- 信誉值达到要求
- 累计交易额达到要求
- 完成指定关键任务
（3）关键任务门槛
即使信誉和交易额足够，如果没有完成关键剧情任务，也不能直接提升到下一信任等级。

这样可以避免“纯数值刷商人”，让商人养成更有角色感。
3. 商人偏好行为
三位商人看重的东西不同，信誉获取逻辑也不同：
商人	核心偏好	喜欢的行为	厌恶的行为
护甲商人 玛拉	履约、秩序、可靠	按时交付、完成护送、保护物资	违约、丢失货物、破坏合作
军火商 埃德加	结果、数据、保密	完成危险委托、带回武器数据、保密	泄露渠道、私吞样品、临阵退缩
医生 林岑	坦诚、病例、救助	提交暴露信息、救助幸存者、带回样本	隐瞒状况、滥杀、破坏医疗委托


4. 解锁商品逻辑
商品解锁应满足“职业成长感”：
护甲商人
- 低级：基础头盔 / 低级甲 / 普通背包
- 中级：中高级护甲 / 更大背包 / 功能性防护装备
- 高级：高阶护甲 / 顶级头盔 / 稀有战术背包 / 特殊防护用品
军火商
- 低级：基础枪械 / 低级弹药 / 简易配件
- 中级：主流制式枪械 / 中阶配件 / 中级弹药
- 高级：高阶枪械 / 稀有弹药 / 高级配件 / 特殊实验弹药
医生
- 低级：基础回复品、绷带、止痛药
- 中级：高级治疗品、损伤处理药、常用针剂
- 高级：稀有针剂、异常处理药物、实验制剂、高价值救急用品
5. 道德选择原则
请注意以下原则：
- 玩家不应该因为拒绝某个商人的不道德要求，就永久失去商店毕业装备。
- 玩家可以通过其他任务路径证明价值，最终仍可获得高等级信任。
- 不同选择应该影响：
  - 折扣
  - 特殊商品
  - 某些任务分支
  - 商人态度
  - 某些剧情真相的获取方式
但不要让“想拿高级货 = 必须帮坏人做坏事”。
三、三位商人完整设定
1. 护甲商人——玛拉·维恩（Mara Vane）
基本信息
- 性别： 女
- 年龄： 48岁
- 职业定位： 护甲 / 头盔 / 背包 / 防护用品商人
- 阵营倾向： 守序中立，偏守序邪恶
- 关键词： 秩序、合同、账本、资源分配、现实主义
公开身份
原环礁湾港务体系的防护物资采购负责人，灾后经营防护装备与战术背包生意。
核心人物概念
她不是热心商人，也不是单纯奸商。
她的信条是：
秩序比公平更重要，承诺比情感更可靠。

她相信在灾难中，资源必须被严格分配。
这意味着她愿意守合同、守规则，但未必在乎规则是否残酷。
过去经历
第一次潮汐期间，她曾参与港区撤离阶段的：
- 防护装备调配
- 运输资源分配
- 名额审核
- 撤离优先级判定
她掌握过谁能拿到护具，谁能上车，谁被延后。
她并不否认自己在那个时期做出过冷酷的决定。

她保存了当年部分账册与调度记录。
这些记录既是她的资本，也是她的原罪。
性格特点
- 说话稳，态度礼貌
- 观察力很强，善于判断对方是否可靠
- 极少情绪失控
- 不喜欢混乱、抱怨和“讲感情不讲代价”
- 不是骗子，但会利用信息不对称
- 很少直接拒绝人，更常用“你暂时还不够资格”处理关系
核心矛盾
她相信自己只是在履行职责。
但她也确实从灾难中获利，并在某些时刻把资源优先给了更“值得保住”的人。
对玩家的看重
她最看重：
- 是否守约
- 是否能按要求带回货物
- 是否能保护资产
- 是否值得她为其预留稀缺名额
商品成长
- Lv.1： I–II级护甲、基础头盔、小型背包
- Lv.2： III级护甲、中型背包、基础防护组件
- Lv.3： IV–V级护甲、高级头盔、战术背包
- Lv.4： VI级护甲、稀有防具、高级防护装备
信任任务方向
1. 遗失货单：回收一批丢失的护具记录
2. 封存仓单：进入旧仓储区查找调拨账册
3. 最后一班运输车：调查一支在撤离时被取消通行资格的车队
4. 账本之外：在高信任阶段接触她真正保留的撤离记录
关键人物弧光
- 前期：可靠、专业、像个精明供应商
- 中期：逐渐显露其冷酷与资源分配逻辑
- 后期：玩家理解她并非嗜血，而是把“秩序”看得高于“仁慈”
代表台词
- 初识：“柜台上的都是公开货。价钱写着，规矩也写着。”
- 熟客：“你守时，也不多嘴，这种人值得我留货。”
- 揭露过去：“当时谁都想上车。可车位不是祈祷出来的。”
- 高信任：“别把我当好人，也别把我当恶人。我只是把账算清楚。”
2. 军火商——埃德加·洛克（Edgar Locke）
基本信息
- 性别： 男
- 年龄： 55岁
- 职业定位： 枪械 / 弹药 / 配件 / 改装商人
- 阵营倾向： 混沌中立，偏中立邪恶
- 关键词： 技术、风险、实验、灰色渠道、结果导向
公开身份
退役军械技术员，经营武器柜台与枪械维护服务。
核心人物概念
他是一个懂枪、爱枪、信技术的人。
他并不迷恋战争，但他迷恋武器在极限条件下的表现。

他的逻辑是：
枪械本身无罪，问题只在于谁来使用，以及谁愿意承担代价。

过去经历
他曾长期活跃于灰色军火流通领域，为：
- 安保承包商
- 地下武装
- 特殊护送队
- 封锁区外围行动队
提供枪械、弹药与维修支持。

在潮汐之后，他逐渐对“异常目标对抗武器”产生兴趣，开始收集：
- 异常环境射击数据
- 特殊穿透效果记录
- 武器故障与弹道反馈
- 针对异常目标的弹药测试结果
性格特点
- 干瘦、精明、说话不快
- 有一种不安定的幽默感
- 乐意解释枪械性能，但对货源闭口不谈
- 关注结果，不太在乎过程是否危险
- 珍惜自己性命，不会轻易亲自冒险
- 对武器品质有职业洁癖，不允许劣质货混进自己柜台
核心矛盾
他尊重技术，却不总是尊重技术作用对象的生命。
为了验证某些理论，他愿意让别人替他承担风险。
对玩家的看重
他最看重：
- 是否能完成危险委托
- 是否能带回实战数据
- 是否懂保密
- 是否足够冷静，不会因为恐惧坏事
商品成长
- Lv.1： 基础枪械、I–II级弹药、基础配件
- Lv.2： 主流枪械、III级弹药、常规改件
- Lv.3： 高阶枪械、IV级弹药、高级改装服务
- Lv.4： 稀有枪械、V级弹药、特殊改装与实验弹药
信任任务方向
1. 失踪枪箱：找回一批遗失枪械
2. 回收弹壳：指定地图实测某类弹药并带回数据
3. 第十七次试射：回收一次失败实验任务的样枪和记录
4. 枪口之后：高信任阶段接触他利用拾荒者进行测试的证据
关键人物弧光
- 前期：专业、有趣、看起来很可靠
- 中期：逐渐发现他在拿别人测试风险边界
- 后期：理解他并非杀戮狂，只是把生命成本过度工具化
代表台词
- 初识：“口径、用途、预算。按这个顺序说。”
- 熟客：“你带回来的数据比大多数活人都诚实。”
- 揭露过去：“我没骗他们安全。我只是没替他们问第二遍。”
- 高信任：“你还活着，说明你配得上更好的枪。”
3. 医生——林岑（Lin Cen）
基本信息
- 性别： 女
- 年龄： 41岁
- 职业定位： 医疗品 / 针剂 / 损伤处理 / 异常处理药物商人
- 阵营倾向： 守序善良，后期可向混沌善良偏移
- 关键词： 救治、病例、隐瞒、临床记录、执念
公开身份
原环礁湾市立医院急诊医生，现经营诊台与医疗物资供应点。
核心人物概念
她是真正想救人的人。
但她最大的危险，也来自这种“必须救下”的执念。

她的核心信条是：
只要还有可能，就不该轻易放弃。

过去经历
第一次潮汐期间，她参与了：
- 大量伤员急救
- 异常暴露病例记录
- 灾后紧急医疗分流
- 一项高度保密的异常患者观察计划
她见过一些按常规医学已被判定无救的人，仍保有某种“意识”或“反应”。
她也见过这些人被当作研究对象继续维持，而不是被真正救治。

之后，她带走了部分资料，并持续尝试研究异常状态下的人体变化。
性格特点
- 温和、克制、有耐心
- 习惯先听完再记录
- 对普通患者有明确同情心
- 不轻易训斥他人，但能用平静语气逼人说实话
- 在医学问题上非常认真
- 一旦涉及“可能仍然活着的人”，会变得异常执拗
核心矛盾
她的善良没有消失。
问题在于，她开始无法接受“无能为力”这件事。

为了救一个可能还有意识的异常患者，她可能愿意投入不合理的资源、时间乃至他人风险。
对玩家的看重
她最看重：
- 是否如实报告接触史
- 是否愿意帮助幸存者
- 是否提交可靠病例信息
- 是否不会轻率放弃可能存活的人
商品成长
- Lv.1： 基础治疗品、止痛药、绷带
- Lv.2： 高效回复品、损伤处理药、常规针剂
- Lv.3： 高级针剂、稀有医疗品、异常处理药物
- Lv.4： 实验制剂、特殊急救品、顶级医疗补给
信任任务方向
1. 失踪病历：回收旧医院病历夹
2. 隔离区样本：获取异常暴露样本或病例数据
3. 仍有生命体征：调查一个持续运转的生命支持系统
4. 不被允许结束的救治：高信任阶段参与她对异常患者的最终判断
关键人物弧光
- 前期：温和、可靠、像真正的医生
- 中期：发现她隐藏了大量异常病例资料
- 后期：理解她的执念与痛苦，并面对“救人是否也该有边界”的问题
代表台词
- 初识：“哪里受伤、接触过什么，慢慢说，不用急。”
- 熟客：“你能活着回来，说明你至少还肯听劝。”
- 揭露过去：“他们说那些人已经无药可救。可我不相信结论能代替人。”
- 高信任：“我不是想证明自己是对的。我只是……不想再那么轻易放弃任何一个人。”
四、三位商人的隐藏联系
为了让三条支线不完全割裂，请加入一条弱关联主线：
共同背景
在第一次潮汐后期，曾存在一场秘密撤离 / 运送行动。
三人都与此事有关，但各自隐瞒了部分真相。
- 玛拉：参与物资与通行名额调配
- 埃德加：提供行动武器与弹药支持
- 林岑：参与人员筛查 / 异常患者医疗判断
设计原则
- 这条线是三人之间的“暗连接”，不是唯一人生中心。
- 不要让三位商人显得像只为这一件往事而存在。
- 他们各自还必须拥有独立任务线、独立问题与独立价值观。
剧情效果
玩家在不同商人任务中，会逐步得知：
- 三个人都没有完全说谎
- 但三个人也都没有说出全部真相
- 每个人都隐瞒了最不利于自己的那一部分
五、任务与信任实现建议
1. 每位商人的任务结构
建议每位商人至少设计：
- 2个基础跑腿/回收任务
- 2个中期调查/风险任务
- 1个关键剧情任务
- 1个高信任揭示任务
2. 任务奖励组成
奖励不应只有钱，应包括：
- 商人信誉值
- 商人经验/信任进度
- 新商品解锁
- 折扣或预购资格
- 特殊剧情资料
- 稀有样品/专属道具
3. 商品解锁规则建议
升级条件建议采用三重门槛：
示例
玛拉 Lv.3 解锁条件
- 信誉值 ≥ 60
- 累计交易额达到要求
- 完成任务《封存仓单》
玛拉 Lv.4 解锁条件
- 信誉值 ≥ 85
- 累计交易额达到更高要求
- 完成关键任务《最后一班运输车》
六、实现要求（给 Agent）
请按以下方向实现：
1. 商店系统
需要支持：
- 三位商人独立商店页面
- 商人独立库存池
- 商品等级随信任解锁
- 商品价格支持差异化设置
- 特殊商品支持“限购 / 预留 / 条件解锁”
2. 商人数据结构
建议包含：
- 基础信息
- 商店类型
- 人物简介
- 信任等级
- 信誉值
- 当前库存
- 解锁条件
- 任务列表
- 台词池
- 剧情状态
- 是否已解锁特殊商品
- 玩家选择分支记录
3. 对话系统
每位商人应有：
- 初识对话
- 普通购买对话
- 低信任对话
- 中信任对话
- 高信任对话
- 任务接取对话
- 任务完成对话
- 关键剧情对话
要求对话能体现人物差异，而非只有功能性句子。
4. UI表现建议
商人界面建议包含：
- 角色半身像 / 立绘
- 商人名称与职业标签
- 当前信任等级
- 信誉值进度条
- 解锁条件说明
- 当前可接任务
- 当前商店库存
- 一句当前阶段代表性台词
七、NPC形象绘制总要求
下面是给绘制 Agent 用的统一美术要求。
总体风格要求
请三位商人形象统一在以下风格下绘制：
- 时代感： 20世纪90年代架空工业社会

八、三位NPC单独绘制提示词
1. 玛拉·维恩 NPC提示词
角色定位：护甲商人 / 物资调配者 / 冷静精明的中年女性

绘制提示词：
设计一名女性 NPC，48岁，护甲商人，架空20世纪90年代工业世界背景。她是封锁区外围的防护装备供应商，曾参与灾难时期的物资调配。外形成熟、干练、沉稳，宽肩，身材结实但不过分夸张，短而微卷的深色头发，面部线条清晰，眼神冷静、审视感强。服装以实用主义为主，穿赭黄或棕褐色系工作衫，外搭耐磨帆布马甲或工装背心，衣着整洁但有使用痕迹。身上可带软尺、记账本、钥匙串、标签夹等物资管理者元素。她的一只手可以扶着防护背心或护甲样品，另一只手压着一本账册或夹着清单。整体气质像一位守规矩、懂生意、很有城府的资源分配者。风格写实偏概念设计，适合游戏 NPC 立绘，背景简洁，可轻微表现仓库、货架、防具陈列的感觉。

关键词补充：
- stern middle-aged woman
- quartermaster
- tactical gear merchant
- ledger, canvas vest, practical clothing
- trustworthy but cold
- 1990s industrial dark setting
2. 埃德加·洛克 NPC提示词
角色定位：军火商 / 军械技术员 / 危险但专业的老练男性

绘制提示词：
设计一名男性 NPC，55岁，军火商，架空20世纪90年代工业世界背景。他曾是军械技术员和灰色渠道武器供应者，现在经营枪械、弹药与改装服务。外形消瘦、略高，灰白短发或寸发，戴矩形眼镜，面容干瘦、带些疲态，但眼神敏锐。整体给人一种危险、精明、技术派的感觉。服装以深蓝、灰黑、旧军工色为主，可穿钢蓝工装、深色马甲、耐用夹克或旧战术外套，整洁但不浮夸。手上可以拿弹匣、子弹、枪械零件，桌上有工具、维护布、出入库簿。气质应该体现“懂枪、懂风险、但不完全可信”的感觉。不要画成狂徒或土匪，更像有技术洁癖的地下军火商。风格写实偏概念设计，适合游戏 NPC 立绘，背景可轻微表现武器柜台、工坊台面、枪械拆解环境。

关键词补充：
- older male arms dealer
- gunsmith
- thin, sharp, gray hair
- rectangular glasses
- pragmatic, dangerous, intelligent
- weapon parts, ammo, workshop desk
- 1990s covert industrial atmosphere
3. 林岑 NPC提示词
角色定位：医生 / 医疗商人 / 温和但有执念的女性

绘制提示词：
设计一名女性 NPC，41岁，医生兼医疗品供应者，架空20世纪90年代工业世界背景。她曾是环礁湾急诊医生，现在在封锁区外围经营诊台和医疗补给。外形端正、克制、温和，黑色头发盘起或束起，面容略有疲惫感，眼神平静但专注，给人可靠、理性、带一点压抑悲悯的感觉。服装以象牙白、灰白、浅卡其、橄榄绿等柔和颜色为主，可穿医生外套、实用衬衣、简洁长裤，不要现代时尚白大褂感太强，而要有长期在临时医疗环境中工作的实用痕迹。可以手持纸质病历夹、钢笔、药盒，桌面有绷带、药瓶、记录本等元素。整体气质应表现为“真正想救人，但似乎背负了沉重病例与秘密”的感觉。风格写实偏概念设计，适合游戏 NPC 立绘，背景可轻微表现临时诊台、药柜、旧医疗设施。

关键词补充：
- female field doctor
- calm, compassionate, tired eyes
- tied dark hair
- medical coat, paper records, medicine supplies
- kind but obsessive
- 1990s emergency clinic atmosphere

十、设计总结
这三位商人的核心区别必须明确：
- 玛拉·维恩：
  “秩序高于公平。”
  她可靠，但冷酷。
- 埃德加·洛克：
  “结果比代价更重要。”
  他专业，但危险。
- 林岑：
  “只要还有可能，就不该放弃。”
  她善良，但执拗。
请确保最终设计达到以下效果：
- 玩家一开始把他们当商店
- 中期把他们当信息来源
- 后期把他们当真正的人物去理解
也就是说，最高信任等级的意义不只是“能买更高级的货”，而是：
这些有城府、有秘密、有过去的人，终于愿意让玩家接近他们真正的那一面。
