# 文物藏品

> 21 件（antiq01–09 / art01–05 / lux01–05 / spec01–04）。收集品，不可使用，只进图鉴与交易。
> 本文件记录 2026-10 的整批修订与随后的扩充：13 件重写文案，再补 8 件（第七批）。

## 一、这批东西在讲什么

文物藏品是**人留下过的东西**，不是自然界本来就有的，也不是工厂批量生产的。
它和另外两类容易混：工业器材讲"还能不能用"，异常遗物讲"它自己会动"；文物藏品只讲**谁用过、怎么用的**。

二十一件按价值来源分六组：

| 组 | 物品 | 值钱的原因 |
| --- | --- | --- |
| 自然标本 | 贝壳、干燥的植物、矿石标本、菊石化石 | 保存状态与采集信息，几乎不值钱 |
| 民俗器物 | 彩绘陶瓷面具 | 手艺还在，但没人记得含义 |
| 地方史与工艺史 | 门牌铜片、手绘航海图、工业釉色母版、环礁湾雕刻铜版 | 只有在这座城市里才有意义 |
| 艺术与出版物 | 黑胶唱片、小幅油画、电影首映海报、限量游戏卡带 | 版本、来源、技法 |
| 钟表与钱币 | 座钟、黄铜怀表、错版硬币、珐琅音乐盒 | 可估价、可流通、可熔 |
| 奢侈藏品 | 金条、机械腕表、钢笔、蓝宝石胸针 | 材质本身就有价 |

这个分组决定了价格曲线：自然标本与民俗器物停在白绿（¥1,600–7,200），
艺术出版物与钟表跨蓝紫（¥16,000–96,000），奢侈藏品与两块工艺母版落在金红（¥200,000–1,650,000）。
**价格不是按"好不好看"排的，是按"能不能换成钱"排的。**

## 二、三条价值来源，彼此不通用

**材质**：金条 ¥200,000 全部来自一公斤金子，没有故事，也不需要故事。它是全库唯一一件
"描述里明确写了它没有故事"的物品——这句话本身就是它的定位。

**工艺**：座钟、怀表、腕表、钢笔靠加工精度立足；珐琅音乐盒（¥268,000）与蓝宝石胸针（¥340,000）
是这条线的顶点，贵在"多层烧制"和"设计师确定的非对称"。它们比金条还贵，因为比金子更难做。

**身份**：错版硬币 ¥80,000 的材质只值几块钱，溢价全在"这一批压偏了"。这一批新增的三件
**版本类收藏**都走这条路：首映海报贵在"被撤换的原始片名字体"，游戏卡带贵在"初回限定 + 编号证书"，
手绘航海图贵在"港口扩建之前的测量"。**同一件东西，换个批次就是另一个价。**

三条来源不能混着写。给金条编一段来历，或者给釉色母版强调"厚重金属"，都会把价值说虚。

## 三、两块工序母版（这是红档的第二种来源）

红档原本只有一个理由——**原型机**（电子类的工程原型、深海核心）。第七批给文物补了第二个理由：**母版**。

| | 工业釉色母版 | 环礁湾雕刻铜版 |
| --- | --- | --- |
| 价值 | ¥400,000 | ¥1,650,000 |
| 定的是什么 | 颜色 | 城市 |
| 唯一性 | 工艺首次标准化时的那一块 | 整套全景图唯一留存的手工原版 |
| 与后续产品的关系 | 之后所有产品都对它配色 | 之后的印刷品都从它印出来 |

两者的差别值得记住：**釉色母版是"标准"，城市铜版是"记录"**。前者规定了以后该长什么样，
后者保存了本来长什么样——所以铜版里留着那些在最终印版上被删掉的旧建筑：菜市场、旧电影院、沿街书店。

城市铜版还兼着一条世界观职责：它是**灾变前环礁湾城市形象的唯一实物依据**，
后续旧城区地图、历史建筑与地方艺术的设定都可以从这里取。釉色母版不承担这个，它只说明"这里有工厂"。

## 四、和异常遗物的边界

文物藏品里有三件带着"不对劲"的暗示：贝壳出现在三楼、座钟停在一个接近满潮的时刻、
菊石化石的背面保留着原始沉积面（时间被压进石头里）。三件都**只给线索，不给结论**——
描述里没有超自然现象，分类依据里写明本体没有异常性质。

分界很硬：异常遗物必须**自己会动**。回响结晶会自己出声，潮汐仪里的微型海洋永远保持水平，
停摆的怀表每天都停在同一秒。文物藏品只会**停在某个状态**，不会维持它。

## 五、和情报资料的边界

`手绘航海图` 是本批最容易归错的一件：它是图，标注了航道、暗礁与测深点，看起来像情报。
归文物藏品的理由写在依据里——**它描述的是一个已经不存在的港口**。图上的几处码头在扩建中拆了，
水深数据被红笔改过，它不能用来导航，只能用来证明"这里曾经可以停船"。

分界：**情报资料是现在能用的信息**（旧报纸的日期、底片里可能有东西），**文物藏品是过去状态的记录**。
一张能用的海图是情报，一张失效的海图是文物。

顺带一个 ID 问题：这批的「电影首映海报」原文写作 `art03`，但 `art03` 已被情报类的「摄影底片」占用，
而物品 id 同时是存档图鉴的键，改名会丢玩家进度。所以海报改用 `art05`，
`art04` 留给游戏卡带（原文如此），`art03` 保持原样。

## 六、上一轮的三处实质修正（13 件那一轮）

**金条 5kg → 1kg。** 旧数据重量是 5.0kg，描述写的却是「一公斤」，两个数字一直对不上。
按描述取 1kg：一块标准交割金条的重量，也是一个人能塞进背包带走、但会明显拖慢脚步的重量。
旧文案"拿一块就够走一趟了，但你就走不动了"随之作废——1kg 走得动，所以新文案改成
"熔了以后，还是一公斤金子"。

**座钟删掉"纯属巧合"。** 原文是"指针停在潮水涨满的那一刻，纯属巧合"。
这句话替玩家把结论说了，而且说得心虚。新文案只写"停在一个接近满潮的时刻。没人知道它究竟停了多久"——
**巧合要玩家自己发现，写出来就变成了作者的解释。**

**错版硬币的术语。** 旧描述"压错了模具"是错的：模具没坏，是币坯在冲压时偏移了。
改为"偏心冲印"，并补上"部分外缘没有完整压出"这一条可观察的物理后果——错版币的鉴定就看这个。

## 七、第七批补的四个空位

第七批 8 件不是平均铺开的。文物原本是**哑铃形**：白绿四件都是"捡来的"零碎，金红四件是贵重物，
中间两档反而是空的。这一批主要补中段。

| 档位 | 物品 | 补的是什么 |
| --- | --- | --- |
| 绿 | 彩绘陶瓷面具 ¥7,200 | **第一件"有人做过的"低档文物**：此前白绿四件全是标本与旧物，没有手工艺品 |
| 蓝 | 电影首映海报 ¥21,000、菊石化石 ¥26,000 | **普通收藏**：有版本、有出处，但不贵 |
| 紫 | 限量游戏卡带 ¥78,000、手绘航海图 ¥96,000 | **主力收益**：这一批的骨干，两件都是"成套保存" |
| 金 | 珐琅音乐盒 ¥268,000、蓝宝石胸针 ¥340,000 | **工艺与材质各一件**，把两条线分别推高 |
| 红 | 环礁湾雕刻铜版 ¥1,650,000 | **第二种唯一性来源**：母版（见第三节） |

分布因此变成 白 2 / 绿 3 / 蓝 5 / 紫 4 / 金 5 / 红 2。
**金档 5 件与生活用品并列全库最多**——因为金档只认三件事：贵金属、复杂工艺、限量身份，而文物三样都占。
工业器材金档只有 1 件（量块组），电子 2 件，医疗 3 件。

- 螺旋（贝壳、菊石）／方片（门牌）／圆片（硬币、怀表、腕表、胸针主石）／梯形块（金条）／细长条（钢笔）

- 第七批有四件是"平面"，最容易画成同一块板子，必须分开：海报**竖版、卷曲、深蓝**；
  航海图**横卷、米黄、多彩线条**；铜版**横版、暗红、厚重、四角氧化**；卡带**小、厚、深紫**
- 黑胶唱片靠"露出半张封套"形成方与圆的对比；珐琅音乐盒靠椭圆与半开的盖内金色滚筒
- 釉色母版与城市铜版都以"密"取胜，但一个是**色块阵列**，一个是**线条阵列**，缩略图必须能区分

## 九、边界

- 不承担世界观揭示。这批东西只说明"这里有人住过"，不说明"这里发生过什么"。
  唯一的例外是城市铜版：它明确提供了灾变前城市的形象，供地图与建筑设定取用。
- 不引入鉴定、拍卖、修复玩法。价格是交易估值，不是鉴定结果。
- 不为凑档位新增物品。文物藏品的件数由"这座城市留下了什么"决定，不由稀有度分布决定。
