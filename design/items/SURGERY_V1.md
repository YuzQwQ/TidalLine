# 重伤治疗道具补充 · 提案 V1.0

> 状态：**草案，未实现**（2026-11-06）。只写设计与代价，不动代码。
> 关联：[医疗系统](MEDICAL.md)、[经济体系](ECONOMY.md)、[稀有度](RARITY.md)

## 一、先纠正一件事

"没有手术包"不成立——`heal12` 外科手术包早就在，效果也接好了：

| 物品 | 稀有度 | 重量 | 价格 | 效果 | 读条 | 次数 |
| --- | --- | --- | --- | --- | --- | --- |
| 医用夹板 `heal10` | 良品 r2 | 0.5 kg | ¥6,000 | 解骨折 | 3.0 s | 1 |
| 外科手术包 `heal12` | 孤品 r5 | 1.6 kg | ¥110,000 | 重伤 −1 层；无重伤时解骨折 | 8.0 s | 2 |

真正的问题不是"没有"，是**结构上的三处缺口**：

1. **买不到**：医生货架按 `i.r <= 3` 过滤（`base.js` 的 `renderDoctor`），紫金医疗品一律靠探索。手术包是 r5，玩家在货架上永远看不到。
2. **没有中间档**：夹板 6,000 治骨折，手术包 110,000 治重伤，中间空着。重伤一发生，玩家的选择只有"忍住"或"撤"。
3. **单件不够用**：重伤最多叠 4 层（每层 −15% 上限，100 → 85 → 70 → 55 → 40%），一件手术包只有 2 次、每次 8 秒且受击打断。叠两层以上时，一件包只能救回一半。

顺带说明掉率——实测（各容器 20,000 箱，`Loot.fill` 直接跑）：

| 容器 | 品质 | 手术包出现率 | 约多少箱一件 |
| --- | --- | --- | --- |
| 医疗柜 M | 优质 | 4.21% | 24 箱 |
| 急救器材箱 H | 优质 | 4.03% | 25 箱 |
| 救援人员背心 Y | 优质 | 3.12% | 32 箱 |
| 防水补给箱 K | 贵重 | 7.88% | 13 箱 |
| 皮质旅行包 A | 贵重 | 0.87% | 115 箱 |
| 床头柜 N | 普通 | 0.03% | 3,333 箱 |

原因是医疗类 r5 只有两件（`heal05` 精密医疗箱、`heal12` 手术包），医疗容器又偏重医疗类，所以在医疗柜里它并不算稀客。**"捡得到、但买不到、但也不够用"**——这才是缺口。

## 二、方案 A（建议先做）：加一件 r3 战地缝合包

| 项 | 值 |
| --- | --- |
| ID | `heal19` |
| 名称 / 简称 | 战地缝合包 / 缝合包 |
| 稀有度 | 上乘 r3 |
| 重量 | 0.55 kg |
| 价格 | ¥26,000（r3 价格带 9,000–38,000 内） |
| 效果 | 重伤 −1 层，**不解骨折** |
| 读条 / 次数 | 12.0 s / 1 次 |
| 分组 | `trauma`（损伤处理） |
| 掉落 | 正常进医疗容器池，不设 `noLoot` |
| 医生 | r3 会自动出现在货架上，不需要改货架代码 |

设计意图：

- **贵在"慢"**：12 秒对 8 秒，交火里基本用不出来，只能在清完场或躲进房间时处理。它买的是"确定性"，不是"战斗中的续命"。
- **不解骨折**：避免直接替代 6,000 的夹板——骨折仍走夹板，缝合包只负责重伤这一条线。
- **价格为夹板的 4.3 倍、手术包的 24%**：重伤是"整局上限受损"，值得花钱；但还不到孤品价。
- **一件一次**：一件只能退一层，叠两层就得两件。4 层重伤仍需要多件或撤退，保留压力。

实现要点（后续落地时）：`effect: { kind: 'surgery', cures: 'severe', useTime: 12, uses: 1 }`。现在 `Debuff.surgery()` 是"有重伤治重伤、没重伤解骨折"的二选一，需要让它认 `cures` 字段；`surgeryAvailable` 也要跟着只认重伤。文案（`Medical.actionText`）相应变成"进行缝合（治 1 层重伤）"。

## 三、方案 B（可选）：再补一件 r4 便携手术器械组

| 项 | 值 |
| --- | --- |
| ID | `heal20` |
| 名称 / 简称 | 便携手术器械组 / 器械组 |
| 稀有度 | 珍罕 r4 |
| 重量 | 1.1 kg |
| 价格 | ¥58,000（r4 价格带 22,000–110,000 内） |
| 效果 | 重伤 −1 层，或解骨折 |
| 读条 / 次数 | 9.0 s / 1 次 |
| 医生 | 需要货架白名单（r4 不在 `i.r <= 3` 里），按 `STOCK_UNLOCKS_V1.md` 排 Lv3 |

三件式梯度会变成：夹板 6,000（骨折）/ 缝合包 26,000（重伤，慢）/ 器械组 58,000（重伤或骨折，中）/ 手术包 110,000（两条都能治，快，2 次）。

**但方案 B 的收益偏薄**：比缝合包只快 3 秒、贵 3.2 万，还要额外开白名单、占一个 r4 医疗位（会稀释 `heal04` 野战医疗包）。除非以后要做"手术成功率 / 器械消毒"这类机制，否则不建议现在加。

## 四、医生上架

- 方案 A 落地后，`heal19` 是 r3，**自动进现有货架**，`shopNote` 那句"出售寻常、良品、上乘医疗品"不用改。
- 手术包维持 r5 探索获取，和"紫金恢复药靠探索"的定位一致。
- 若采纳方案 B，需要把 `renderDoctor` 的过滤从"稀有度"改成"显式白名单 + 信任等级"，并与 `design/merchants/STOCK_UNLOCKS_V1.md` 的 Lv2/Lv3 表对齐；这会牵动 `merchant-ui` 的库存展示，属于另一轮改动，本提案不展开。
- 限购：r3 医疗品目前不限购，缝合包建议同样不限购（价格本身就是闸门）。

## 五、对现有体系的影响

| 项 | 影响 |
| --- | --- |
| 重伤规则 | 不变（每层 −15%，最多 4 层，不致死，撤销时截断当前 HP） |
| 夹板 | 不变，仍是骨折的唯一便宜解 |
| 手术包 | 不变，仍是唯一能"重伤/骨折二选一 + 2 次"的道具 |
| 恢复药 | 不变，仍不能治重伤（只按容量回血、可止血） |
| 跨局 | 不变，重伤仍是局内状态，撤离即清 |
| 掉落池 | 医疗类 r3 从 3 件变 4 件，`heal03/heal08/heal13` 各自在 r3 医疗内的占比下降约 25%；总量与稀有度曲线不变 |
| 经济 | 物品总数 218 → 219；收集品计数不变（医疗品不进图鉴） |
