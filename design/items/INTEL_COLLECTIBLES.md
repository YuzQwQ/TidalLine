# 情报收集品

> 15 件（intel01–intel13 新增，life02 旧报纸、art03 摄影底片为原有）。收集品，可进图鉴与交易。
> 与「异常遗物」的分界：情报是**纸面上的记录**，异常是**会自己动的东西**。

## 一、这一类原来只有两件

情报资料在本次扩充前只有 `life02 旧报纸` 与 `art03 摄影底片`，都是**居民视角**：
一张报纸、一卷底片，任何普通人都可能留下。办公文件柜的偏好是 `['intel','life']`，
但"情报"只有两件，柜子里翻到的多半还是生活用品——偏好挂钩了，货架上却没有货。

这次补 13 件，把视角从居民一路推到机构内部：

| 段 | 件数 | 物品 | 视角 |
| --- | ---: | --- | --- |
| 城市记录 | 4 | 旧电话簿、港口货运清单、城市建设蓝图、电报码底稿 | 城市在正常运转 |
| 灾变行政 | 4 | 撤离登记卡、磁带录音、潮位观测日志、封锁区通行名册 | 有人在组织、在记录、在放行 |
| 专业调查 | 4 | 实验原始数据盘、撤离电台录音带、异常区域勘测报告、未公开调查卷宗 | 机构开始研究自己看不懂的东西 |
| 首潮观测 | 1 | 首潮原始观测记录 | 异常第一次被测量 |

**这是一条渐进的发现路径**：普通城市记录 → 灾变期间的行政资料 → 专业调查档案 → 首潮原始观测记录。
玩家不必读完全部文件也能判断战利品的价值，但愿意细看的人能拼出"从正常运转到灾变、封锁、撤离"的过程。

## 二、三类载体，三种证据

这一批刻意把载体摊开，不让情报又变成一堆长得一样的档案盒：

| 载体 | 物品 | 它证明什么 |
| --- | --- | --- |
| 影像 | `art03` 摄影底片（原有） | 有人拍下了什么，但需要显影 |
| 音频 | 磁带录音、撤离电台录音带 | 有人说过什么，但需要设备回放 |
| 数字 | 实验原始数据盘（3.5 英寸软盘） | 仪器测到了什么，但没有软件读不出来 |
| 纸面 | 其余九件 | 写下来的、盖章的、能直接读的 |

**底片、磁带、软盘不能混为一谈**：底片对应影像记录，磁带对应声音记录，软盘对应仪器输出的数字。
三者的共同点是"**拿在手里也看不见内容**"，这正好是情报类最有意思的地方——
你能带走它，但不一定读得懂它。声明的读取手段都留给以后的任务系统。

## 三、数量与稀有度

分类合计 15 件：寻常 2 · 良品 2 · 上乘 4 · 稀见 3 · 珍罕 3 · 孤品 1。

注意这个 2/2/4/3/3/1 **已经包含原有的旧报纸与摄影底片**（旧报纸是寻常、底片是上乘），
所以"新增 13 件"与"分类 15 件"是两回事，两者并不矛盾。

情报类的价格不跟材质走——它全是纸、磁带和塑料壳，单件材料成本可以忽略。
价格跟**"谁能拿到这份东西"**走：

- 电话簿 ¥1,800：公开印刷，谁都能买；
- 货运清单、登记卡 ¥5,200–6,800：窗口柜台上的东西；
- 蓝图、会议录音、电报底稿 ¥24,000–32,000：要进到科室里才拿得到；
- 潮位日志、通行名册、数据盘 ¥58,000–96,000：专业岗位的连续记录；
- 电台录音、勘测报告、调查卷宗 ¥220,000–460,000：跨机构、且没有副本；
- 首潮观测记录 ¥1,850,000：只有那一册，且后来的报告引用过它。

## 四、和军事类的那条历史关系

`intel13 首潮原始观测记录`（¥1,850,000）与 `mil15 首潮撤离标图板`（¥1,600,000）指向同一个历史阶段，
但**不是同一件事**：

| | 首潮原始观测记录 | 首潮撤离标图板 |
| --- | --- | --- |
| 机构 | 早期观测站（水文/科研） | 军方指挥单位 |
| 视角 | 异常**第一次被测量** | 人**如何被组织撤走** |
| 载体 | 线装观测簿 | 金属框标绘板 |
| 结论 | 数据对不上，校准却正常 | 通往港口的线路改了三次，最后没画到港口 |

一个是"我们测到了什么"，一个是"我们怎么应对"。两者可以互相印证，但任何一件都不能单独解释灾变，
**这是刻意的**：情报给物证，不给答案。

## 五、情报不负责解锁地图

这一批全部先按**交易收集品**处理：能捡、能卖、能进图鉴、有描述，但**没有一件会解锁地图或任务**。

原因很实际——把"读文件"做成解锁条件，会让不愿读文本的玩家卡住；而这一批的价值本来就该由
"它是什么"来决定，而不是"读了它能打开什么"。等任务系统成熟后，可以挑少数几件
（勘测报告、调查卷宗、首潮观测记录）赋予信息读取或线索解锁功能，其余保持纯收藏。

## 六、掉落

含 `intel` 偏好的容器有六个：`W 废纸篓`、`m 帆布挎包`、`D 运动包`、`F 办公文件柜`、
`Q 通讯设备箱`、`O 密封公文包`、`I 机密封存箱`。这批进来之后，办公文件柜终于名副其实。

需要留意的是品类占比的变化：情报此前只在 r1、r3 两档有物品，高档位一律让份额，
所以密封公文包长期是"文物 67% / 情报 4%"。补齐 r2、r4、r5、r6 之后，
情报在每个档位都有人，公文包才可能真的像个装文件的东西。

## 七、美术

本轮新增的 `intel01–intel13` 共13件图标已使用内置图像生成工具逐件绘制，并接入游戏、物品清单、Wiki和离线单文件。交付为48×48透明像素图，最多16色，四边预留4像素透明边距；原有旧报纸与摄影底片图标保留。

[查看图标总览](../../assets/item-art/intel/index.html) · [完整提示词与生成记录](../../assets/intel-generation.json)。透明原稿保存在 `assets/item-art/intel/sources/`，可运行 `node tools/prepare-intel-art.js` 重新整理图标。

十三件里九件是**纸**，最容易画成一叠同样的白纸。分辨靠三件事：**纸形、配色、附件**。

| 物品 | 靠什么认 |
| --- | --- |
| 旧电话簿 | 厚书 + 深绿封面 + 阶梯索引边 |
| 港口货运清单 | 长条窄纸 + 红色印章（唯一横向长条） |
| 撤离登记卡 | 米黄卡片 + 蓝色圆章，最小的一张 |
| 城市建设蓝图 | 深蓝底 + 白色管线网格（唯一蓝底） |
| 磁带录音 | 透明壳 + 两个白卷轴 |
| 电报码底稿 | 极窄长条 + 蓝色时间戳，纸面全是字 |
| 潮位观测日志 | 摊开的硬皮簿 + 夹着白色纸带 |
| 封锁区通行名册 | 深绿窄册 + 红色权限标记（唯一"册"而非"页"） |
| 实验原始数据盘 | 三张错开的方片 + 金属滑盖（唯一非纸质主体） |

最后一件要单独说：它的缩略图必须让玩家看出**左页整齐、右页开始乱**——
表格被借用成地图，这是全批唯一一张"看得出记录者当时在想什么"的图。

## 八、边界

- 不解释灾变成因。十三件里最贵的两件都只给过程，不给结论。
- 不引入"阅读/解码"玩法。本批没有一件带 `use`，也没有一件有解锁字段。
- 不与军事物资重复：情报记录"发生了什么"，军事记录"怎么应对"。
- 不为凑档位新增物品。情报的件数由"一座城市会留下多少种记录"决定。
