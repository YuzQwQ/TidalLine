# 生活用品（29 件）

生活用品不是"某一国度的民俗陈列柜"，而是证明**环礁湾曾经是一座拥有复杂社会生活、不同职业、
不同习惯和不同历史的人类城市**的证据。本文件记录这一类的取舍标准、逐件结果，以及被移出物品的去向。

世界观依据：[设定档案 v0.1](<../world setting/TidalLine_世界观设定档案_v0.1.docx>)。
城市所在的国家、历史、地理与文化**尚未定稿**；已明确的只有三条：接近 20 世纪 90 年代的工业文明、
长期存在的隐秘超自然现象、灾变后被封锁数年的沿海城市。

## 三层结构

不复刻任何一种现实文化，也不做"东西方各占一半"的配平。生活用品按三层组织：

| 层 | 内容 | 作用 | 在本类中的比重 |
| --- | --- | --- | --- |
| **基础层** 工业时代的通用生活 | 搪瓷器皿、电话机、电子玩具、工业消费品、办公用品、交通与服务设施 | 建立玩家对"这个时代"的基本认识 | 多数 |
| **文化层** 不同社会传统的交汇 | 丝绸服饰、成套瓷器、特殊裁剪与工艺 | 显示这座城市与外部世界有过往来，但不指向单一来源 | 少数 |
| **独有层** 环礁湾自己的文化 | 本地机构、公共宣传、商业传统、工艺学派、重要历史事件 | 让玩家能把它和现实世界区分开 | 精而少 |

配套的两条审美原则：

- **文化特色不等于昂贵和稀少。** 一枚异国银饰在玩家眼里可能是收藏品，在制作它的文化里只是家常器物。
  地域特色鲜明的普通物品可以少，但不必规定它们只能出现在金红层；稀有度仍由工艺、材质、保存状态和历史身份决定。
- **先立通用库，再补地域层。** 等城市的文明确立之后，再有目的地加入地方特色，而不是现在每种文化各塞一件。

## 大筛选：保留 18 件

从原来的 35 件里，只保留**有必要占一个位置**的。判断标准不是"有没有意思"，而是"是否不可替代"。

### 直接保留（13）

搪瓷缸、铝饭盒、磨损的硬币、老式台灯、铁皮饼干盒、玻璃糖罐、未拆封的毛巾、
玻璃弹珠袋、铁皮玩具火车、双铃闹钟、真皮手提箱、银餐具一套、金丝眼镜。

其中三件补了细节，让价格和描述站得住：

- **双铃闹钟**：从"每次走到 5:47 都停"改成明确的机械故障——分针传动齿轮缺一齿，
  背面贴着一张修表匠的纸条："齿轮缺一齿，非磁化，非进水"。与停摆的怀表（异常遗物）彻底分开。
- **银餐具一套**：明确为**纯银**，手柄背面打着成色印记，材质本身支撑起金档。
- **金丝眼镜**：明确为**实金**细框、手工磨边镜片，而不是模糊的"金丝"。

## 移出生活库（17）

不是从世界里删除，而是换一个用途。它们仍是好东西，只是不该挤在生活用品里塑造城市印象。

| 物品 | 处理 | 原因 |
| --- | --- | --- |
| 塑料拖鞋、塑料梳子、搪瓷脸盆 | 场景装饰 | 普通且残损，独立掉落价值不足；脸盆与搪瓷缸重复 |
| 红双喜暖水瓶、铝制高压锅、花露水 | 暂时移除 | 地域指向明显 / 重量低辨识度 / 待日用化工线明确 |
| 竹编食盒、梳妆镜台、樟木箱 | 容器 / 场景家具 | 作为可搜索对象比直接出售更有玩法价值 |
| 铜制手炉、竹骨麻将、红木算盘、银质长命锁、潮绣被面 | 收藏品候选 | 应由材料、工艺与历史支撑其金档价值，适合与其它传统的工艺品并列出现 |
| 铜火锅、铜汤婆子 | 暂时移除 | 文化指向集中，且与同类取暖炊具重复 |
| 搬家木箱 | 场景叙事 / 任务物品 | 普通迁居箱撑不起孤品价值 |

长命锁、潮绣被面和竹骨麻将**不是坏设计**。它们是非常有意思的文化遗物，只是过于集中地影响了整座城市的文化印象。
以后它们应当和其它文化传统的特色物品一起，进入高价值收藏品，并配有独立的工艺来源——
那样玩家找到的会是"一种特殊文化的作品"，而不是"全城居民都过同一种日子"。

## 掉落接入

生活库从 35 件收敛到 29 件后，`js/core.js` 的权重模型没有改动：

```
每件权重 = rBias[稀有度] × 类别偏好 / 该档类别权重和 / 该类别在该档的件数
```

因为档内先按类别归一、再按件数平分，**减少或增加同类物品只改变花样，不改变容器该出什么**。
40000 次抽样（抽样脚本见 `tools/sample-drop.js`）：

| 容器 | 稀有度 白/绿/蓝/紫/金/红 | 类别构成 |
| --- | --- | --- |
| 工具箱（快 · 偏工业） | 62/29/6/2/1/0 % | 工业 51% · 生活 13% |
| 电子设备柜（标准 · 偏电子/工业） | 41/34/16/6/3/0 % | 工业 36% · 电子 19% · 收藏 14% |
| 医疗柜（标准 · 偏医疗） | 40/34/15/6/3/0 % | 医疗物品 42% · 收藏 14% |
| 防水补给箱（重型 · 生活/医疗/工业） | 10/23/30/21/14/2 % | 生活 30% · 医疗物品 29% · 工业 15% |
| 住宅抽屉（标准 · 偏生活） | 40/34/15/7/3/0 % | 生活 46% · 收藏 15% · 医疗 11% |

与收敛前的记录相比，五类容器的稀有度曲线与类别构成都在 ±1 个百分点内。

## 下一步：按区域分化掉落

生活用品不再增加同类物品。接下来让**地点**决定掉落的文化味道：

- **普通住宅**：家庭用品、廉价消费品、个人财物。
- **旅馆与商业街**：旅行用品、纪念品、促销赠品、高级消费品。
- **工业生活区**：工人用品、标准化工业消费品、旧式机械产品。
- **港口与沿海设施**：船员用品、远洋消费品、航运企业遗留物。
- **历史街区**：地方传统工艺、古旧日用品、民俗收藏品。

这些只是候选，不需要现在就把城市布局定死。目的是：即使两处掉落同一稀有度的物品，
玩家也能感到明显的探索差异。
