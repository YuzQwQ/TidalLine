# 恢复药优先止血

恢复药剩余容量至少50且玩家流血时，先读该药原有的启动时间，完成后一次性扣50容量解除流血，再直接持续回血。没有第二段启动读条。容量不足50仍可回血，但不能止血；绷带总容量20，因此保留回血用途。满血或已达重伤恢复上限也能使用足量恢复药止血。

中断未完成的读条不扣这50容量；止血完成后中断，已解除的流血和已扣容量保留。恰好剩50容量时只止血，随后移除耗尽药物。读条期间流血仍持续，止血完成前不会回血；持续回血期间新出现流血，会暂停并重新读条止血。读条期间流血被其他来源解除时，不再收取止血容量。

同类快捷药优先选择足够止血的残件／整件；背包与安全箱按钮读取所选条目的实际容量。止血阶段HUD明确显示倒计时和容量消耗。局外治疗不受此规则影响，止血带等专用效果品保持原规则。

容量消耗配置：`CFG.DEBUFF.BLEED.HEAL_CAP_COST`。逻辑与说明统一由`Medical`提供，Wiki物品页复用`Medical.summary`。
