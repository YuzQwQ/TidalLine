# 本局损耗

局内背包标题右侧显示。每局结束开局配装载入后建立独立账本；下局清零。初值覆盖背包、保险箱、枪械及其余弹／已装配件、头盔、护甲、背包装备和近战武器。

按参考原价而非商人回收折扣计算：护甲为原价×当前耐久／出厂耐久，药物与钥匙按剩余容量或次数折算，普通物品按数量。枪械本体、弹匣内子弹和配件分别估值；换弹、退弹和拆装配件不重复计价。背包现值也采用这套状态折算。

带入的独立物品有仅本局有效的来源标记，局内新拾取的同种战利品不抵消损耗。带入物品离开随身装备／背包／保险箱时，剩余价值计损；原物捡回后恢复其剩余价值。装卸、换装备、保险箱转移保留来源。

弹药与同型号配件属于可合并资源，按带入部分优先消耗：新增资源不补回已经消耗的带入数量。枪内弹药与背包弹药合并计数；已装配件与散件合并计数。符号标记不写入JSON存档。
