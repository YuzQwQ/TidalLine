# 医疗系统首版

医疗品共18件，属于物资，不进入收集图鉴；当前总物品统计见Wiki。收集品中的注射器和X光片仍属于医疗物资，不能治疗。

## 治疗与生命值

前五件恢复药是**容量制持续治疗**，不再是一口回满：

| 物品 | 启动 | 速率 | 容量 |
|---|---:|---:|---:|
| 绷带 | 2.0 秒 | 10 HP/秒 | 20 |
| 安禾无菌敷料 | 1.8 秒 | 12 HP/秒 | 60 |
| 家庭急救包 | 1.5 秒 | 15 HP/秒 | 120 |
| 制式野战医疗包 | 1.2 秒 | 20 HP/秒 | 200 |
| HV-300 精密医疗箱 | 0.8 秒 | 25 HP/秒 | 400 |

药品**不堆叠**：全项目只有子弹能叠在一起，药品一件占一格（仓库、背包、安全箱都一样）。

使用后先进入**启动阶段**（不回血、不扣容量），启动结束才按速率持续恢复；每实际恢复 1 HP 扣 1 点容量。满血自动结束，容量不足只恢复剩余容量，容量归零时物品移除。没有单次治疗上限，一件药可以一路用到满血或容量耗尽。

治疗期间**可以正常走动，速度降为 30%**；冲刺、攻击、换弹、切枪、闪避、投掷、死亡会打断。普通受击不打断。中断后已恢复的 HP 保留，已扣容量不退；启动阶段被打断不扣容量。同一时间只允许一种治疗在跑。

容量记在物品条目上：每件药自带一份容量，格子里显示剩余容量。用过的药**单独占一格**（本来就不叠），剩余容量随它走。残容量随仓库、撤离和存档保留；老存档里没有容量字段的一律按满容量初始化，容量为 0 的直接清掉。

局外（藏身处）从库存使用立即回血，不走启动和持续流程，同样按实际恢复扣容量，剩余容量保留。目前不提供补充容量的道具。

局内除了在背包里点物品，还有一条更快的路：**短按 `5`** 直接用当前选中的药，**长按 `5`（250 毫秒）** 弹出圆形轮盘挑一种。轮盘按背包格子顺序分种类，同一种只占一个扇区，选完松手就用，同时把这个**类型**记成默认——之后短按 5 一直用它，直到这种药在背包里找不到了才回退到排序最靠前的可用药。同种类有多个实例时先用容量的那件。治疗中短按不会重启，换药会先正常中断当前治疗。

屏幕下方常驻一条医疗快捷栏（`[5] 图标 ×5` 或 `320/400`），治疗进度条单独占一层，开背包也压不住它。打开、关闭背包都不会中断治疗——治疗状态在医疗系统里，跟背包界面无关。

新玩家和旧存档缺失生命值时默认100HP。撤离保留HP，死亡及其他失败回到1HP，再次出发继承。无自然回血。生命值随受伤和治疗存档，刷新不自动回满。医疗品左键打开操作面板，可使用、移入/移出安全箱或出售，面板里直接显示启动时间、速率与当前容量；另有6件已开放为损伤处理用品（3种止痛药、止血带、夹板、手术包），仍保留7件「效果待开放」，只有这7件不能消耗、不参与掉落池。

## 医生与携带

医生复用其他商人的货架及确认界面，出售白绿蓝医疗品10件，每次购买一件，采用物品表定价；其中2件仍标记效果待开放，购买前明确提示；止血带、夹板与三档止痛药已可在行动中使用。紫金恢复药通过探索获取。

医生立即补满HP：绷带等效成本为 `ceil(缺失HP / 20) × 2,000`，另加 `max(1,000, ceil(等效成本 × 25%))` 服务费。缺20/50/99HP分别收3,000/7,500/12,500信用点。满血不收费，余额不足不交易，确认时重新核价。局内损伤在战局结束时自动清除，局外不提供损伤清除（诊所只补 HP），无救济折扣。

绷带保持默认携带3件、最高5件；仓库不足按2,000信用点补购，保留现有破产救济规则。其他医疗品只能从库存选择，每种至多一堆，不自动购买。出发前检查库存、格数与负重；失败不扣钱或物资。购买或搜到的未开放品也可携带，但当前不能使用；六件已开放的损伤处理品可以带进局使用。

旧med01库存与引用迁为heal01，合并数量；med02/med03收集品不变。存档键不变，版本升为3，新增hp及loadout.medical。批量出售寻常物仅处理寻常收集品，保留所有弹药和医疗品。

## 数据与美术

[medical.json](medical.json) 是18件医疗品的源数据，保留完整描述、绘制要求及未来效果。执行 `node tools/build-medical-data.js` 同步运行数据；物品清单和离线构建也会自动同步。18件医疗品图标已全部绘制并装载（含按新描述重绘的绷带），统一48×48透明PNG、硬边透明、4px留边、16色内调色板。医生、仓库、背包、安全箱、搜刮与离线版共用。原稿、提示词与质量报告保存在assets/item-art/medical及assets/source/prompts/medical-generation.json；[查看18件图标总览](../../assets/item-art/medical/index.html)。

医疗产业及物品中新增历史叙事见[提案文件](<../world setting/医疗产业提案.md>)，暂不视为已确认的正式历史。正式世界观文档保持原样。


当前价格以 [economy.json](economy.json) 为准，医疗描述与药效继续由medical.json提供。诊费最低服务费随绷带价按50%换算，详细表见[经济体系](ECONOMY.md)。


## 损伤状态与医疗（第二轮）

四种状态：**流血 / 重伤 / 骨折 / 疼痛**（疼痛是派生效果，不单独掷概率），外加临时增益
**镇痛**。感染、异常侵蚀、肢体独立血量、水分能量、成瘾耐药中毒暂不实现，状态对象与配置
里已留字段。状态只挂在玩家与 `human:true` 的人形敌人（拾荒者、据点看守、受雇回收员）上，
机械守卫与回响体完全免疫；人形敌人共用状态机但没有医疗/镇痛 AI。**局内状态不跨局保留**，
死亡 / 撤离 / 超时 / 潮水都在 `showEnd()` 统一清除，不写 `Save.debuffs`。

### 触发

`Debuff.onHit(target, ctx)` 是唯一致伤入口，由 `Player.hurt` / `Enemy.hurt` 在扣血之后调用。
攻击元数据由四个发射点生成，同一次攻击（含霰弹 6 弹丸）共享 `attackId`，所以一发只掷一次骰；
每目标另有 0.45 秒判定节流，压住 800~1000rpm 与 burst。护甲完全抵挡或实际掉血低于 0.5 不触发
（现有弹药穿透矩阵最低仍有 15% 蹭伤，这条语义为将来矩阵出现 0 项预留）。致残率与伤害、穿透、
弹药等级、武器稀有度解耦：枪按 `category` 从 `tools/build-arsenal.js` 带出 `attackType` 与
`injuryChanceMul`，敌人按 `cd` 归一（`0.16 × cd`，限 0.10~0.32）。

| 攻击类型 | 致残率 | 流血 / 重伤 / 骨折权重 |
|---|---:|---|
| 普通枪弹 `bullet` | 0.18 | .55 / .30 / .15 |
| 霰弹 `shotgun` | 0.22 | .68 / .22 / .10 |
| 锐器 `sharp` | 0.30 | .80 / .15 / .05 |
| 钝器 `blunt` | 0.26 | .08 / .22 / .70 |
| 冲撞重击 `heavy` | 0.30 | .10 / .40 / .50 |

### 效果与治疗

| 状态 | 效果 | 解除 |
|---|---|---|
| 流血 | 1.5 HP/秒，最低保留 1 HP 不致死；不影响移动/瞄准/翻滚；不叠层 | **只有止血带** |
| 重伤 | 每层降低基础最大生命 15%，0/1/2/3/4 层 → 100/85/70/55/40%；触发时把超过新上限的当前 HP 截断（不额外扣血、不致死）；持续产生疼痛 | 手术包每次治 1 层，不回血 |
| 骨折 | 疼痛派生（移速 −22%、翻滚距离 −25%、冷却 +35%、散布与准星抖动）；**每次翻滚额外掉 4 HP**（无视护甲、不触发致残、镇痛不能免除）；不叠层 | 夹板，或手术包（无重伤时） |
| 疼痛 | 由重伤 / 骨折动态派生，不随层数叠加；镇痛期间完全屏蔽 | 镇痛 / 治好对应损伤 |
| 镇痛 | 90 / 180 / 300 秒三档；重复服药取 `max(剩余, 新时长)`；未受伤可提前服；不治愈任何损伤、不恢复上限 | 时间到自动恢复惩罚 |

普通恢复品（绷带与 heal02–05）只能回到当前可恢复上限，不解任何损伤。手术包按状态二选一：
有重伤治 1 层，无重伤但有骨折解骨折，两者都没有则不可用；读条 8 秒且**受击打断**，
其余医疗动作沿用「受击不打断」。止血带 2.5 秒、夹板 3.0 秒、止痛药 1.0~1.5 秒。
`CFG.DEBUFF.ANALGESIC.WATER_MULT` 是「药效期间水分消耗倍率」的预留参数，本轮无读取点。

六件开放物品（`design/items/medical.json` 的 `effect` 字段）与仍待开放的 7 件：

| 物品 | effect | 次数 |
|---|---|---:|
| 安禾止痛片 heal06 | 镇痛 90 秒 | 1 |
| 复方镇痛胶囊 heal07 | 镇痛 180 秒 | 1 |
| 强效镇痛剂 heal08 | 镇痛 300 秒 | 1 |
| 止血带 heal09 | 解除流血 | 1 |
| 医用夹板 heal10 | 解除骨折 | 1 |
| 外科手术包 heal12 | 手术（重伤 / 骨折二选一） | 2 |
| heal11、heal13–18 | 效果待开放，不进掉落池 | — |

效果品的「容量」字段复用为使用次数，`Save.normalizeList` 与拆件/合并逻辑按 `Medical.capOf()`
统一处理，残次数跨存档保留。局外（仓库 / 藏身处 / 保险箱）没有局内损伤可处理，这六件按钮
显示「只能在行动中使用」并禁用。

### UI 与生命周期

局内 HUD 新增 `#debuffBar` 状态条（流血 / 重伤层数与上限 / 骨折 / 疼痛 / 镇痛倒计时），
血量条把被重伤封锁的一段画成暗红并标出上限线。用医疗品后当帧刷新状态条、快捷栏与治疗读条。
`showEnd()` / `beginDying()` / `startRun()` 三处清状态，`Game.update` 每帧 `Debuff.tickAll(dt)`
结算流血。详见 `js/debuff.js`、`js/config.js` 的 `CFG.DEBUFF` 与 `tools/test-debuff.js`。
