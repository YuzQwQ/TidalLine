- 出售规则：全部 8 把钥匙（含 001 测试、003/004 通用模板、四间房卡）都挂在维克托货架上，按 `price` 原价出售、不乘 `priceMultiplier`，买→卖必亏 25%。供货/限购后续再调。

## 开锁读条

钥匙房（`doorType:'locked'`）按 E 先插钥匙：画布中央出现金色读条，标「开锁中 · 1.2s · 别动」，时长 `CFG.LOCK_TIME = 1.5` 秒。

起手时 `DoorSystem.unlockHint()` 只做只读检查（有没有对应钥匙），**不改门状态、不碰耐久**；读满那一帧才由 `Game.applyDoor()` 调用 `DoorSystem.prepareOpen()` 扣 1 点耐久、置 `unlocked`，然后开门并播放 `door_open_alt`。开锁声 `unlock_key` 在起手响一次（0.72s 的「钥匙插入门锁音效」，见 `tools/import-unlock-audio-v1.js`）；受阻门被踹开时改播 `door_kick`。

**任何动作都会打断**：新增按键（移动、切枪、换弹、背包、医疗、冲刺…）、鼠标左右键、闪避／换弹／近战动作、实际位移、打开面板、走远、滚轮、Esc、再按 E，以及受击。起手那一刻按下的 E 记进快照，松手不算新动作。打断只清读条，门仍锁、钥匙一点不扣、存档不写。

`Game.syncRaidChain(true)` 只在开锁成功后把剩余耐久写回存档；关页／刷新仍走不带参数的空链保护路径，避免局内链尚未装好时抹掉存档里的钥匙。

## 钥匙链

挂在身上的 6 格钥匙位，位置在藏身处「备战 · 装备与携带」的保险箱下方，**只在局外调整**。它解决的是「出门要带好几把钥匙，可背包格本来就紧」这件事——不是保险箱，不能当免费仓库用。

| 规则 | 说明 |
| --- | --- |
| 容量 | 6 格，只收钥匙；非钥匙会被 `Save.normalizeChain()` 退回仓库，不静默吞掉 |
| 局外 | 背包或仓库的钥匙右键「挂到钥匙链」放入；链上格子双击移回背包，右键还有「放回仓库」 |
| 局内 | 只读：能开门并正常扣耐久，拿不出来也放不进去（格子里只有「详情」） |
| 背包 | 不占格、不计负重、不计背包价值——`Bag.chain` 独立存放，不进 `weight()` / `value()` |
| 战损 | 钥匙的耐久消耗照常计入「本局损耗」，`RaidValue.scan()` 会扫描这条链 |
| 结算 | **撤离和阵亡都原样回档**（保留局内已消耗的耐久），不会清空、也不会被打散进仓库或背包；结算收获价值里不算它 |
| 断线 | 出发时**不清空** `Save.chain`，局内拿的是副本；每开一次锁由 `Game.syncRaidChain()` 把剩余耐久写回存档，关页 / 刷新前再兜一次。刷新页面只丢这一局，钥匙和已扣的耐久都还在 |
| 开锁顺序 | 钥匙链 → 背包 → 安全箱；同款钥匙同时挂在链上和包里时先扣链上的 |

配置在 `CFG.BAG.CHAIN`。实现：局外 UI 是 `js/base-keychain.js`，局内只读格与结算在 `js/game-panels.js`，开锁查找在 `js/doors.js` 的 `findKey()`，存档字段 `chain`（`Save.flush` / `load` 按缺字段兜底，老存档不用迁移）。

> 定位说明：钥匙链是「死亡不掉落的钥匙专用位」，和 4 格安全箱分工不同——安全箱放什么都行、死了也回得来，钥匙链只放钥匙、同样死不掉，但换来的是一把不占背包格。代价是它不会替玩家省钱：钥匙耐久在局内照常消耗，只是不会连钥匙一起赔进去。
