# 商人批量出售系统

四位商人共用真实三栏出售页：左侧保留角色、台词与主营说明；中间为真实仓库、容量、分类/九类子类、名称搜索、品质、排序和分页；右侧为紧凑详情、独立滚动的待售清单与固定结算。沿用原稀有度纯色，选中金边勾选，拒收采用暗层与禁止标记。正式收集品分为低价60%、常规80%、偏好100%三个档位。

## 规则

- 埃德加收枪械、近战、弹药、配件；玛拉收头盔、护甲、背包；林岑收医疗道具（含待开放效果）；维克托收九类收集品，包括医疗类收集品。
- 收集品按已确认的九类默认与20个单品覆盖采用60/80/100%；装备及物资沿用现有专业回收范围与价值口径。配置支持允许类别、类别倍率、按物品覆盖与拒收；未来商人通过配置接入。低价状态相对unitPrice计算，不采用参考图的演示折扣。
- 基础价格沿用unitPrice：装备保持既有半价/耐久折价，改装配件随枪报价，枪中余弹不额外退款或自动退弹。绑定刀具不可出售。
- 仓库出售入口现为“前往出售”，跳转商人总览；不能绕过商人直接按100%成交。仓库金额均标为估价。

## 选择与事务

单击整个物品格切换待售并查看详情、右键仅查看详情、Shift单击加入整堆、角标/清单移除、清空、修改正整数数量。装备只能一件。筛选/排序/分页及同商人购买/出售切换保留选择；切换商人、离店或进入战局清空并使确认失效。待售清单不持久化。

WeakMap把实际仓库条目映射为会话内稳定ID，型号、数组下标和当前页均不参与定位。条目被规范化重建或移出时旧选择失效，不追认同型号替代品。

preview不改库存。确认令牌保存商人、数量、条目状态与报价指纹；commit重新检查局外状态、当前商人/出售模式、仓库成员资格、重复实例、数量、绑定限制及价格。任何一项变化整笔拒绝，不能跳过错误行或自动降低数量。令牌仅用一次，取消、关闭、切换或离店后不能提交。

提交先生成新仓库与资金，再通过原存档键一次写入同份JSON。剩余堆叠保留原物品字段。flush失败时恢复旧库存引用和余额，不播放成功音效；成功才统一刷新并播放一次sell。仓库只导航，不再发起交易。
