# 仓库 UI 交付记录

[独立布局稿](index.html) · [规划](PLAN.md) · [开发版](../../../index.html#base) · [验证结果](validation.json)

采用左侧分类、中间库存、右侧常驻详情。实际游戏保留600格容量、六档品质与当前堆叠规则；分类计占格，详情显示件数／发数。九类收集品可展开，不与可使用的医疗物品混淆。

搜索、品质和排序先于分页执行；排序为视图操作，不重写库存顺序或合并不同品质。出售寻常收集品增加确认和库存变化复核，装备、弹药、医疗品不在其范围。使用、入包、出售和退弹仍调用原有业务。绑定刀具不可售，失败不扣库存。

原仓库DOM按页面所有权在仓库、商人出售与备战之间移动，不产生第二份库存。js/storage-config.js、js/storage-ui.js、assets/ui/storage.css可分别调整分类、行为适配和视觉。锁定、维修、多选批量处理没有业务实现，入口明确说明待开放。

没有新增场景PNG；图标和静态背景复用。开发版与离线版共享模块，使用`node build.js --assets-only`同步，不重编地图。

验证：`node tools/test-storage-ui.js`覆盖四种宽度1440／1280／390／320、真实使用和入包、满背包、弹药按格计数、药物剩余容量、绑定保护、整理不改数量、九类分离、批量取消／确认／双击、报价过期拒绝、节点归还。独立稿localStorage为空。预览使用隔离测试库存，不操作玩家存档。

`node tools/test-merchant-ui.js`和`node tools/test-safehouse-ui.js`回归通过。主回归`node run-test.js`为302通过、0失败。
