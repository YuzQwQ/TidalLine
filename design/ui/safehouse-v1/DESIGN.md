# 藏身处 UI 改版设计 v1

状态：布局与美术规划，未接入游戏。参考 `temp files/藏身处UI改良参考.png`。本轮不绘制正式背景，不修改存档、商店、装备和离线版。

## 核心选择

把藏身处拆成“空间总览”和“操作工作页”。参考图中房间占据主体、入口有空间位置、行动按钮固定的关系值得保留；现有仓库和商店的高密度格子继续服务于实际整理，避免把格子、装备、商人全部压在总览。

当前版本实际有：生命与信用点、装备与背包、600格仓库、三位商人、收费治疗、收集图鉴与地图选择。仓库每页格数随屏幕变化，不在设计里写死90格。现有医疗品可能存在剩余容量，物品格保留容量与数量标识。装备槽按实际数据生成，长枪横向展示，背包容量与总负重分别显示，负重上限取配置，不能把“背包格数”误作重量。

## 桌面布局

以1440×900为主要评审尺寸；1280×720仍能找到所有主要操作。

1. 顶部72px：左侧潮汐线标识；中间四项主导航“藏身处 / 备战 / 仓库 / 商人”；右侧仅信用点与设置入口。图鉴归于仓库内的二级入口。没有第二货币、玩家等级或设施等级。
2. 页面标题行：位置名、简短用途和当前页标题；不放大号升级进度条。
3. 总览主体：左侧约72%是同一视角的避难室插画；右侧约28%、最小280px是出行检查。不要把状态卡压到场景里遮挡入口。
4. 场景入口四个：左侧无线电桌→商人；中部装备台→备战；右侧药品角→医生；近前景货架箱柜→仓库。它们是可点击的功能入口，不是可升级设施。旁边只显示名称和一句用途，全部功能也可由导航抵达。
5. 右侧出行检查：HP及治疗入口、装备完整性摘要、背包占格、总负重、缺少弹药等可解释提示。“装备为空”不一律禁止出发；沿用游戏已有校验。
6. 右栏底部双按钮：“整理装备”次要，“选择地图”主要。选择地图打开现有地图选择流程，选好地图后才“出发”，不绕过原有最终校验。
7. 底部一行短说明显示当前携带规则；总览不放自动轮播新闻、制造队列或虚构的待办数。必要提示采用局部状态行，不再弹出遮挡入口的新手窗口。

## 备战与仓库

备战页左右约42:58：左侧装备槽与背包，右侧完整仓库。首版复用装备图标，不依赖未绘制的人物纸娃娃。武器宽槽、头盔护甲背包紧凑槽；近战显示跟随最终实装数据，不在本轮新增装备槽。背包容量变化与溢出库存均保留现有处理，不隐藏旧档多余物品。

仓库页扩为主体宽度：顶部搜索、收集品／医疗／弹药／装备筛选、排序、页码；点击物品后右侧详情抽屉给出当前可用动作。物资显示堆叠数，药物还显示剩余容量；稀有度用细色边与小标签，不能只用颜色区分。批量按钮继续叫“出售寻常收集品”，确认框明确排除医疗与弹药。

转移、装备、卸下、出售、退弹保留既有数据校验与确认。左键可以完成全部操作，右键只作快捷方式。抽屉与确认框限制在视口内；Esc依次关闭确认框、抽屉、再返回上一工作页，不触发出售或出发。

图鉴入口先打开已有图鉴内容／页面，不引入任务档案系统；原型只展示入口位置，不加载游戏脚本。

## 商人

二级导航为玛拉／埃德加／林岑，固定位置不随切换移动。左侧约22%为立绘、姓名、职业和简短台词，中部约42%货架，右侧约36%仓库。图片使用已完成的三张立绘，整图等比缩放；窄栏也不裁断人物头部。

医生将收费治疗卡置于货架顶部，与购买药品区分；显示恢复量和最终费用，沿用当前公式并在确认时重算。不得用当前角色设计稿的信任等级直接锁住现有商品。信任、任务和限购留给后续独立系统阶段，本轮布局不展示假进度或可操作的任务页。

## 响应式与可读性

- ≥1200px：上述桌面比例，物品区各自滚动，固定行动区不进入格子滚动容器。
- 800–1199px：右侧检查栏可缩至280px；商人简介折叠为横条，货架与仓库双栏；取消低价值装饰。
- <800px：总览改成背景上方／四张普通入口卡下方，禁止按桌面绝对坐标缩小热点。备战、仓库与商人用子页切换，详情全宽抽屉；底部操作栏占位且计算安全区，避免覆盖最后一行物品。
- 点击目标至少44px；正文14–16px，金额与关键状态16px以上；文字保持足够对比，完整信息不依赖悬浮。焦点清晰、选中态同时用下划线和颜色表示。
- 当前布局稿的所有数字均为演示值，不连接游戏数据。原型库存仅示意筛选和详情，不代表当前游戏库存或交易能力。

## 视觉语言

沿用潮汐线暗绿灰基础，暖黄工作灯作重点，少量旧黄铜用于主按钮、分隔和当前导航。以#101916背景、#1c2824面板、#d9dfcf文字、#c7aa6b强调色为基准；危险只用于明确的低血量／不可交易原因，主出发按钮不再与红色危险态争夺注意力。

场景插画可采用上一批商人立绘的写实概念风，界面里的物品仍用原像素图标；靠统一色温和暗色面板连接两者，而不是把图标放大到插画尺度。UI边框、格子、进度条均用CSS；小型线性图标用统一SVG，不把文字、数字或格子烘焙到背景。

## 要绘制什么

首轮只需新增 **1张正式背景**：`safehouse_room_overview`。三张商人立绘与现有物品／装备图标直接复用；标识和导航图标整理为代码矢量，不必逐个生成PNG。可选的角色整备立绘留到布局接入后，不阻塞首版。

背景交付：2560×1440、16:9、无文字、不透明；主场景采用微俯视的正面剖视房间，不用地图75°顶视角。左侧无线电与旧通信桌、中部挂板装备台、右侧简单药品角、前景一侧储物货架；不摆三位商人实体，不引入生产设施。暖工作灯与冷天光，材质为旧混凝土、钢架、木桌、帆布与纸质记录，符合架空90年代与封锁区外围。禁止霓虹、悬浮屏、满屏枪墙与奢华地下基地。房间不是必须可行走的3D场景。

将可点击物体的识别区保留在图的中央安全区：x10–88%、y15–82%；预设热点中心为商人(20%,42%)、备战(48%,38%)、医生(78%,42%)、仓库(40%,76%)。最终根据成图校准，使用归一化坐标，背景contain完整显示时再定位，不能独立拉伸。小屏取消热点叠放，使用普通按钮。

建议保留分层原稿／无灯光底稿（如生成工具可提供）；实际首版只加载一张压缩背景。最大背景派生1920×1080 WebP，目标≤1MB，低分辨率派生1280×720≤500KB；以清晰度与实际编码结果验收，不强行承诺文件大小。已有关联立绘可生成等比显示用WebP，不覆盖原稿。

完整需求和生成提示词见assets.json。新图是界面背景，不是地图素材，不放入assets/tiles或assets/props；未来如果拆成地图摆件再按场景素材库约定登记。

## 接入顺序与验收

1. 先确认本布局，绘制一张背景，确定热点与缩放安全区。
2. 只重构藏身处视图层：保留Base、Save、Medical和地图选择的数据规则；将仓库、商人和备战渲染区分开，不重写交易。
3. 对应页面按需渲染，切换时清理事件；藏身处不运行游戏主循环，不设置常驻RAF、轮播或自动刷新定时器。静态背景不用canvas实时重绘；非当前商人立绘延迟加载。
4. 检查1280×720、1440×900、390×844：入口不遮挡，详情可关闭，固定按钮不压库存；键盘与鼠标均能完成操作。
5. 接入时回归购买、库存转移、容量／超重失败、治疗、药物剩余容量、弹药退弹与堆叠、地图最终确认、旧档加载；测试长时静置不累积事件或内存，再同步离线版。

本轮交互稿只切换展示、筛选演示物品和查看详情。选择地图弹窗只说明流程，不会发起游戏；未实现的交易不会假装购买成功。
