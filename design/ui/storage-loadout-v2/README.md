# 仓库与战备布局 V2

参考：temp files/潮汐线：仓库界面.png。游戏仓库采用左侧随身装备与背包、中央仓库物资、右侧物品详情的三栏布局。配装方案本轮不实现。

左栏直接复用原有 paneGear、baseGear、baseBagGrid 节点及库存状态，不复制装备或保存第二套库存。仓库内可点击装备格从仓库挑选装备，点击详情“装备”直接换装；主武器可选第一／第二槽。卸下仍使用现有装备选择器。双击仓库装备可换装，其他物品可装包；双击背包物品放回仓库。背包清空、医疗使用和退弹等原有操作仍可用。

装备价值 = 已装备三把枪（含已装配件）、头盔、护甲、背包、近战的参考售价总和。不计包内物资、仓库物品和弹匣内子弹；不按回收折价计算，绑定赠刀依然具有参考装备价值。总负重包括背包内容和身上装备。装备格及背包格均使用与仓库一致的六档稀有度纯色底，选中与悬停只改变边框。

仓库分类移到中央上方，保留分类、九类收集品展开、搜索、品质、排序、分页、详情、确认出售等操作。退出仓库时将共享装备面板恢复到原父节点；商店、备战及改枪入口继续使用原功能。保险箱准备区已在后续补充到背包下方，见 ../base-safe/README.md。

实现：js/storage-loadout.js 为独立布局及交互适配器，assets/ui/storage.css 负责响应式布局。桌面三栏，窄屏上下排列；未添加方案保存或伪造库存。

验证：tools/test-storage-loadout.js（开发／离线、直接换装、主武器选择、双向快速转移、背包容量不足无损失败、满仓库装备返还失败、装备价值排除包内物资、稀有度纯色、节点恢复、存档重开、1600／1280／390／320px）。原仓库与藏身处UI回归通过，主流程402项通过、0失败。结果见 verification.json，截图为 warehouse.png、offline.png、mobile.png 和 offline-mobile.png。
