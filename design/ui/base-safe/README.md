# 局外保险箱准备区

仓库左侧背包格子下方新增保险箱，容量沿用 CFG.BAG.SAFE 的4格，并与原装备／背包面板一起在备战页显示。图标、数量、部分使用医疗品容量及稀有度底色使用现有规则。

仓库物品详情和背包物品浮窗增加“放入保险箱”；保险箱物品点击后可移回背包、放回仓库或使用恢复医疗品，双击移回背包。转移先模拟完整堆叠及容量，失败不改动任何列表；保险箱内容计入总负重，不进入“装备价值”。保险箱内的枪和配件必须先移出才能改装。

Save.safe 保存局外准备物品，旧存档缺少该字段默认空。加载时按现有物品及堆叠规则规范化，超出4格的旧条目退回仓库，不丢失。普通出发时转交 Game.player.bag.safe，并从局外准备区移除，避免复制；靶场不消费保险箱准备物品。

本轮沿用原有局内死亡保护与结算自动分拣：保险箱物品结算后，弹药和医疗品优先回背包，其余回仓库；不会将结算物品另外复制一份留在局外保险箱。玩家可以在仓库再次安排下次携带内容。

实现：js/base-safe.js；数据字段及规范化在 save.js，出发交接在 game.js，局外保险箱医疗品使用通过 Medical 的 basesafe 来源处理。地图选择摘要与总负重包含保险箱，出发药品提醒会识别保险箱内的恢复药。

验收：tools/test-base-safe.js，覆盖4格位置、转移、满格无损失败、医疗容量、存档重开、出发交接、死亡保留及原有分拣规则，开发／离线与390／320px；原仓库战备、医疗24组、配件19组及主流程402项回归通过。
