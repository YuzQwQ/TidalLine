# 物品交互现状盘点

统计范围：藏身处（局外）与行动中（局内）所有"能点的物品"。本文件只记录现状，不含修改方案。

> 后续修订：仓库页已取消右侧 `.st-detail` 概览栏，改为左右两栏（左装备与背包、右库存网格铺满），
> 物品详情统一走 `#itemTip` 浮窗；下文第 4、5 行与 B 行属于取消前的旧状态。

## 四、明确的不一致

1. **左右键语义全局倒置。** 局外：左键=看（仓库、商店）或看+改（出售）；局内：左键=做（拿走/装备/移入安全箱），右键=看。同一个"背包格"，局外左键看详情，局内左键移入安全箱。
2. **局内自己也不统一。** 容器行与尸体格是"左键拿走、右键看"，背包格是"左键动作、右键菜单"；安全箱格又是"左键动作、右键看"。
3. **仓库左右键完全等价。** 两个键做同一件事，右键没有额外价值，还和商店右键（浮层提示）不一样。
4. **出售视图左键带副作用。** 购买视图左键只选中，出售视图左键顺手把物品加进/移出待售清单；两个视图长得一样，行为不一样。
5. **双击只在保险箱存在**（双击=移回背包），其他所有格子双击无意义或触发未知（无 `ondblclick`，浏览器会连发两次 click）。
6. **文案过期。** 仓库/背包格 `title` 写"左键看详情"，实际浮层里才有"放入背包"；浮层 hint 又写"左键放入背包 / 左键放回仓库"，而左键早已不是搬运动作。
7. **同一件装备能做的动作随界面变化。** 仓库里能"前往备战"，背包里能"放入保险箱"，局内背包里能"丢弃"，商店里只能"购买"，改装页只能"换件"。
8. **搜索中的行有右键但只弹 toast**，而它旁边的已搜出行右键是真详情——同一列表里两种右键语义。
9. **详情信息量不对等。** 仓库里看不到"单价/回收价/来源"，商店里看不到"分类/图鉴"，局内容器只能看到"名称/重量/价格"三个字段。
10. **稀有度与分类的呈现方式有三种。** 浮层放头部小字；两个 inspector 放键值行；局内列表行靠左边框颜色 + 徽章。

## 五、下一步可选的统一方向（未实施，待定）

- 方案 A：**左键=选中/看，右键=动作菜单**（桌面惯例）。仓库、商店、出售、局内背包、尸体、容器全部照此收口；双击统一为"快速转移"。
- 方案 B：**左键=主操作（拿/穿/用/移），右键=详情**（射击游戏惯例）。优点是局内顺手，代价是局外仓库/商店要点两次才能确认。
- 方案 C：**左右键都只用来选中，所有动作集中在右侧 inspector 的按钮组**（当前仓库页已经是这样）。改动最大但最一致，且移动端天然只有一种手势。
- 无论选哪个，都建议先把 A/B/C 三套详情合并成一套字段表，再让浮层和 inspector 共用同一个渲染函数，避免以后再分叉。

## 六、统一后的手势（已实施）

四种手势全局统一，格子只描述"这是什么、点下去能做什么"：

| 手势 | 作用 |
| --- | --- |
| 单击 | 看详情。局内详情带动作按钮（使用 / 换装 / 快速移动 / 丢弃），局外只有信息 |
| 双击 | 做：医疗品使用、弹药设为待装填、枪械护甲换装、普通物品看详情；容器与尸体是"拿进背包" |
| Ctrl+左键 | 快速移动（固定）：背包→安全箱、安全箱→背包、容器→背包；局外背包=放回仓库 |
| 右键 | 菜单：详情 / 使用·装备 / 其它（退弹·改装） / 丢弃（永远最后、标红） |

例外与保留：

- 装备槽（武器×3、近战）单击仍是切枪/切近战 —— 战斗高频动作留在左键，双击才是看详情。
- 装备槽右键新增「丢弃」：扔下去的装备成为脚边的物品堆（扔手上那把会自动切到下一把或抄近战）。
- 局内背包里的配件：双击=安装到枪械；枪多一条「退弹」与「改装」。
- 局外藏身处背包：详情只有信息，动作在右键菜单（使用 / 放入保险箱 / 放回仓库）；
  双击=搬回仓库（医疗品双击=使用）。保险箱同理。
- 仓库页与备战页维持旧手势，下一轮再收。
- 局内医疗详情（含"可恢复 X HP"与剩余容量）由统一的 itemDetail 生成，
  原 Medical.open 的局内入口退役（局外仓库详情仍走原面板）。
- 损伤处理品（止血带 / 夹板 / 手术包 / 止痛药）沿用同一套四手势，双击=读条使用；
  局外只读信息，按钮显示「只能在行动中使用」并禁用。详情里的「当前容量」对效果品显示为「剩余次数」。

## 七、仓库页收尾（本轮）

- 仓库格：单击 → 统一浮窗详情，双击 → 放进背包，右键不弹菜单（原来右键也弹详情）。
  装备类不再"双击直接穿上"，装备入口挪到浮窗里的「装备」按钮。
- 背包格与装备槽：单击看详情；双击/Ctrl+左键 = 卸下；右键 = 详情 / 卸下（医疗品多一条
  使用，未满时多一条存入保险箱，枪多一条退弹与改装）。
- 卸下链路统一：优先回仓库 → 仓库满则进背包 → 两边都满才拒绝并提示。背包物品的
  「卸下」就是存回仓库，仓库满则卸不下。
- 右侧 `.st-detail` 不再承担物品详情，改为仓库概览（占用 / 背包 / 保险箱 / 估价 /
  分类占用 / 品质分布）；详情载体从 2 种（浮窗 + 面板）收敛为 1 种。
