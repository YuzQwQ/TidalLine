# 物品视觉更新 · 2026-11-08

本轮统一搜索反馈、局内外物品格与商店货架。未改变搜索耗时、掉落概率、物价或交易规则。

## 搜索与揭晓

- 扫描区域限定在左侧图标框：随真实进度从左向右露出黑色剪影，右侧放大镜持续绕圈。
- 搜索完成立即显示完整贴图，同时播放整行由暗变亮、轻微放大后回落；最大缩放为 1.025。
- 自动搜索重绘列表时续播，不从头闪回；关闭后重开不重播。
- 金、红额外闪亮一次，与亮起同时结束。

| 品质 | 亮起 ms | 放大回落 ms | 闪亮 ms |
|---|---:|---:|---:|
| 白 | 120 | 80 | — |
| 绿 | 220 | 140 | — |
| 蓝 | 380 | 240 | — |
| 紫 | 600 | 380 | — |
| 金 | 900 | 580 | 600 |
| 红 | 1300 | 850 | 1100 |

## 物品格

- 圆角 6px，品质边框 1px，使用偏暗的同色系渐变，取消左侧粗色条。
- 局内高光 2.8 秒绕行一圈；局外固定左上高光，形成轻微立体感。
- 彩蛋边框以粉紫 → 冰蓝 → 青绿 → 香槟金排列，一圈重复两轮，亮度已降低。
  局内 3.6 秒一圈，局外静止；详情“彩蛋”标签使用同套密集四色渐变。
- 最终版本不含额外白色内外描线，也不延长搜索完成后的黑影停留。
- 商店复用仓库的方形布局、图标比例和右下名称，价格放在物品框下方；配件槽点仍保留。

## 测试入口与验证

`doors.html` 是隔离测试场。出生点下方有三个可重置的大型保险箱；上方固定放置彩蛋“颂乐玩偶”，
按 E 可直接拾取，点击“补回样品”可补回。测试物品不写入正式存档。

运行 `node tools/test-item-visuals-browser.js` 验证搜索剪影、六档揭晓时长、彩蛋样式、局外固定高光、
商店方格与价格分离，并生成本目录截图；普通版与离线版均覆盖。
