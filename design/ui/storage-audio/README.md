# 仓库物品操作音效

复用现有音频素材和播放总线，未新增采样或更改音量。

- 装备枪械：沿用局内切枪映射 SWITCH_SFX，霰弹枪为 shot_switch_shotgun，其余当前使用 shot_switch。
- 装备头盔／护甲／背包：SFX.gear 对应 gear_helmet／gear_armor／gear_bag。
- 装备近战：沿用近战切换声（shot_switch，rate 0.86）。
- 卸下回仓库、仓库与背包间转移、保险箱转移、成功退弹到背包：通用 pickup。
- 一键清空背包：实际移回至少一件时仅播放一次 pickup，取代原先的拉链声。
- 自动替换旧装备不叠加第二声；单纯选择／预览、空操作、空间不足、过期条目和失败均不触发物品成功音效。界面按钮既有轻提示音沿用原规则。

装备音入口为 Base.gearVoice；转移音在各自成功提交点触发，未放到列表绘制或选择事件里，避免重复播放。过期源条目先检查归属，防止重复点击重新转移。

验证：tools/test-storage-audio.js。真实解码现有采样，记录最终 _playSample 路径；覆盖枪械、三类防具／背包、近战、卸下、双向转移、保险箱、退弹、清包、失败静默及真实双击。开发版和离线版通过；仓库换装回归、主流程402项通过。
