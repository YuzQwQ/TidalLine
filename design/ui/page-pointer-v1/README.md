# 全页面鼠标锁定

用户要求战斗、藏身处、商店和背包都保持锁定，用虚拟鼠标操作界面。

- 首次点击只捕获鼠标，不触发购买、射击或其它按钮动作。随后按相对位移移动虚拟鼠标，限制在视口内。
- Esc退出原生Pointer Lock，清除按键、射击和拖动状态；再点击页面重新捕获。浏览器可能在Esc后要求稍等再允许捕获。
- 锁定目标是body；`PagePointer` 通过虚拟坐标寻找真实DOM目标，转发点击、双击、悬停和应用右键菜单。禁用控件不接收操作。
- 输入框获得真实焦点，键盘输入照常；下拉菜单用自有浮层，避免原生系统下拉菜单无法用相对鼠标操作；范围滑块支持按住拖动；滚轮沿可滚动祖先滚动。
- 虚拟光标使用顶层popover，原生dialog弹窗上也可见。原有canvas瞄准仍用实际画布坐标转换；内部面板及死亡处理不会释放整页锁定。
- 禁止全页浏览器contextmenu默认动作与鼠标前进/后退侧键，保留物品自定义菜单。锁定不更改存档格式或提供局内进度恢复，不拦截浏览器键盘刷新快捷键。
- 浏览器不支持Pointer Lock时保留原生鼠标操作。移动端触屏不通过mousedown捕获。

实现：`js/page-pointer.js`，由主入口和离线构建加载；Game旧版画布锁定作为独立预览页的兼容路径保留。

验证：`node tools/test-page-pointer-browser.js`。真实Edge的HTTP版与file离线版均覆盖body原生锁定、商店导航、文本输入、下拉选择、范围滑块、滚轮、模态弹窗光标、战斗左右键、背包锁定与物品右键菜单、Esc释放及重新捕获。报告见verification.json；另有463项基础逻辑回归通过。
