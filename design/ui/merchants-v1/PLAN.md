# 商人 UI 改版：总览与商店详情

参考temp files中的商人总览与商店详情两张图；沿用已确认的玛拉、埃德加、林岑，不使用参考中的人物名称或商品定义。

## 差距与结构

原页面是小型人物条加两栏货架／仓库，缺少总览、人物主视觉、购买与出售分区、稳定详情区和未来成长空间。

改为两层：商人总览采用大幅职业立绘卡、独立信任位置、第四张“联络扩展”规划卡、底部消息与委托入口；商店详情采用左侧人物及功能菜单、中部商品筛选与货架、右侧常驻商品详情与确认入口。顶部全局导航继续共用藏身处壳层。

## 能力边界

- 当前开放：三商人联络、现有货架、商品分类／搜索／价格和品质排序、选择查看详情、沿用原确认框购买、仓库出售、医生治疗、余额与库存状态。
- 未开放但保留完整位置：信任进度与下一阶段奖励、任务委托、信任奖励、未来配件与改装、更多合作方。点击给出说明，不扣款、不保存任务或虚构等级。
- 独立视觉稿显示带“演示”标签的信任数字，不读取游戏存档；实际游戏明确显示“信任体系待开放”。不把旧版设计建议的门槛直接当成运行规则，也不建立总体信任等级。
- 当前所有购买按一次一件／既有弹药整盒进行，不加虚假的数量加减。选中商品后看右栏，点击购买仍经过原有交易确认和资金／容量检查。
- 医生的付费治疗与药品购买分开；剩余容量、未开放药效沿用现有医疗数据，不新增效果。

## 工程

`js/merchant-ui.js`负责总览、详情、筛选和选中状态；配置提供各商人的文案、分类、消息和规划能力。Base原有货架只添加稳定offer元数据，UI接管选中表现并保留原购买回调。出售页复用原仓库节点及出售确认，不复制库存与结算系统。只有进入对应页面才移入节点，离开时归还，备战与仓库保留。

CSS独立在assets/ui/merchant.css。共享立绘使用现有原图生成等比高分辨率WebP，不重新绘制人物、不覆盖原稿；背景复用藏身处静态图与渐变遮罩。没有新地图PNG或运行时动画循环。离线版内联新增样式和脚本，沿用地图快照。

## 适配与验证

1440×900三栏详情；1280×720紧凑模式；窄屏总览纵向卡片，详情人物摘要、功能菜单、货架、详情依次排列，出售仓库独立滚动。所有未开放入口有明确反馈，分类与搜索有空结果提示，原商品点击仅选中，不立即扣款。离开页面取消悬浮确认，切换商人重置选中对象。

实施前主回归300通过。验收开发与离线：总览到三商人、筛选排序、详情、余额不足、仓库满、购买单次确认与重复点击、出售、医生治疗、未开放无状态变动、备战／仓库节点归还、窄屏及返回总览；独立演示无存档访问。
