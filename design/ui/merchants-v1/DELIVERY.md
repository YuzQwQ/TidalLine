# 商人 UI 交付

总览与详情共用藏身处全局导航与材质体系。人物使用玛拉、埃德加、林岑的既有立绘，生成640px宽WebP展示派生图；背景复用静态藏身处插画，未新增地图素材。

- 总览：三张可交易人物卡、一张联络扩展规划卡、各自信任位置、公开货架消息、委托入口。
- 详情：人物／功能菜单，分类、搜索、排序与商品网格，常驻右侧详情和交易按钮。桌面参数区滚动，购买按钮保持可见。
- 出售：原仓库节点移入详情，选择真实库存显示回收价；确认沿用原接口。物品操作仍能打开使用、转移、退弹等现有动作。
- 医生：保留真实报价、药品开放状态和收费治疗。未新增伤势或药效。
- 未开放：信任、委托、奖励、配件及扩展合作方均有说明；演示页的等级只标演示，不写入运行进度。
- 交易反馈：购买、出售、失败提示显示在商店内容区，避免原提示隐藏在备战页。
