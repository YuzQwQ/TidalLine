# 通用地面素材库规范

目标：素材按材质与形态复用，地图编辑器负责组合出不同地点。房间、建筑、阵营或地图名称不作为通用地面素材的分类依据。

当前首批设计见 [通用地面素材第一批](GROUND_BATCH_01.md)：6张有色图已绘制，优先统一画风、连铺和材质连接；[预览与质量检查](../../assets/ground-batch-01/index.html)已完成，已接入地图编辑器和运行时预加载，现有地图未自动替换。

## 命名与分类

用“材质＋铺设形态＋必要状态”命名，例如：灰色方砖、旧木板、粗糙水泥、压实泥土、深色沥青。避免“诊所瓷砖”“银行地板”“公寓木地板”等用途命名；诊所、住宅、仓库只作为可选搭配标签，不限制使用。

建议新资源ID：`ground_{material}_{pattern}_{variant}`，例如 `ground_ceramic_square_01`、`ground_wood_plank_01`。磨损、裂缝和积水优先使用独立叠加件；只有明显改变整片材质表现时才制作状态变体。不要预先穷举材质、颜色和状态的所有组合。

现有文件名和地图字符保持兼容，通过登记映射到通用分类；不因规范更新批量改名或改变存档。

## 基础材质系列

| 材质系列 | 建议基础形态 | 可组合出的用途举例 |
| --- | --- | --- |
| 土质 | 压实泥土、碎石土 | 小院、道路边缘、空地 |
| 草地 | 稀疏短草、草土混合 | 庭院、荒地、道路边缘 |
| 石材 | 不规则石板、规整石砖 | 街道、广场、院落、室内 |
| 水泥 | 平整水泥、粗糙水泥 | 室内、室外空地、仓储、维修 |
| 瓷砖 | 小方砖、大方砖 | 家居、公共建筑、商铺、医疗空间 |
| 木材 | 平行木板 | 居住、商业、公共室内、步道 |
| 沥青 | 普通沥青 | 主路、停车区、装卸场 |
| 金属 | 钢板、防滑花纹板 | 平台、工业地面、设备区 |
| 水面 | 平静水面、浑浊浅水 | 水道、池塘、局部积水 |

颜色应形成少量可共同使用的灰、灰绿、灰棕色组。不要为每栋建筑各自生成一套颜色与纹理风格。砖块尺寸、木板宽度、颗粒密度在同系列内保持一致。

## 组合层

1. 基础地面：铺满32×32不透明格，表达主要材质。
2. 材质连接：直边、内角、外角；土、草覆盖边缘可复用透明叠加，石质路缘、门槛作为独立连接件。
3. 状态贴花：裂缝、污渍、潮湿痕迹、少量碎屑，透明背景，不附带实体碰撞。
4. 建筑结构与物件：墙、门、阶梯、家具等独立，不烘焙到地面。

连续铺装先做好同系列边缘相容，再解决不同材质连接。不能只依靠增加地面种类掩盖接缝问题。首批过渡优先覆盖现有高频组合，不为所有材质两两制作完整连接图集。

## 编辑器登记约定（规划）

后续资源条目应描述：稳定ID、通用显示名、图像路径、所属层、材质系列、铺设形态、变体组、连接组、方向要求、可选使用标签，以及是否已绘制。编辑器可以另存“材质组合预设”，如木板＋污渍＋石门槛；预设与基础素材分开。

通行、地形高度、水深、碰撞与视觉资源分开配置。不能因为选用了瓷砖就自动成为诊所，也不能因为绘有水色就自动变为深水。保留现有地图字段兼容；本文件是素材生产和后续登记的约定，不代表现有编辑器已实现上述分层或自动连接功能。

## 下一批优先顺序

- 先统一现有灰绿石砖、庭院铺装、水泥与泥土的明度、颗粒尺度和旧化强度。
- 每个高频基础材质先补2–3张边缘相容变体，变化集中在内部，避免明显重复图案。
- 补通用石路缘、石门槛及土/草覆盖边角，改善当前接缝。
- 然后增加旧木板、灰色方砖、平整水泥、沥青等通用材质。各材质至少在多个不同空间中验证可用性，再按实际地图需求扩充。

验收：同材质3×3连铺、异材质相邻及转角、同一素材在不同建筑/室外的组合效果。所有地面保持每格32px、正交顶视、少量低饱和颜色，不带固定投影或独立地块边框。
