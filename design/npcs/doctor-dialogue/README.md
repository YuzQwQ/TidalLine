# 林岑：商人及医疗服务台词

原样接入用户提供的10句文字：总览1句、问候3句、闲置2句、购买2句、治疗前后各1句。不新增配音、信任状态或医疗规则。

- 总览：医生人物卡展示固定台词。
- 进入医生商店：随机问候，同组避免连续重复；重绘不会覆盖当前台词。
- 闲置：45秒无操作后随机寒暄，之后间隔90秒；点击、键盘、输入、滚动重计。确认弹窗打开时延后，离店或后台清理计时器。
- 购买：医生商品实际成交后随机结算台词。取消、余额不足、不开放商品等失败不会触发。
- 医生治疗：确认框显示治疗前台词；支付成功且确实回血后，商店顶部显示治疗后台词。取消和失败不触发治疗后回应。
- 备战快速治疗：治疗前台词只出现在购买确认框的医生信息中。成功后在健康状态卡显示治疗后台词，不增加结算弹窗。费用、HP、满血限制与原Clinic逻辑保持一致。

通用台词数据为 js/merchant-config.js 的 MERCHANT_DIALOGUE.doctor；商人展示与成功事件适配为 js/merchant-dialogue.js。随机缓存按商人及组别隔离，埃德加与林岑互不串词。治疗确认使用 Deal.show 的可选dialogue字段；Clinic确认框使用相同数据源。

验证入口：tools/test-doctor-dialogue.js；结果 verification.json。覆盖开发版／离线版、320／390px、随机问候／闲置／购买、治疗前后、快速治疗确认限定、取消／失败／重复支付及跨商人切换。原军火商对白、快速治疗和24组医疗回归通过，主流程402项通过、0失败。
