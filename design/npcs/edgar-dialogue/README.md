# 埃德加·洛克：交互台词接入

原样接入用户提供的9句文字台词：商人总览1句、进店问候3句、闲置寒暄2句、购买成功2句、改枪统一采购1句。不增加姓名、背景、任务或信任机制，不生成配音。

- 总览台词出现在军火商人物卡中。
- 每次进入军火商店随机选择问候；同一组避免连续重复。
- 店内没有点击、键盘、输入或滚动操作45秒后随机寒暄，之后至少间隔90秒。操作会重计45秒；交易确认或说明弹窗打开时延后；页面在后台、离店或进入战局时停止计时。
- 问候、寒暄与购买对白使用商店顶部对白区；库存或界面重绘不会覆盖当前对白。
- 枪械、弹药、近战与独立配件购买成功后随机选择结算对白。失败、取消或单纯预览不会触发。
- 改枪统一采购台词显示在购买确认框内、对应商人姓名右侧；窄屏自动换行。结算后不再显示对白卡或弹窗。
- 所有台词为展示状态，不进入存档，不影响经济或NPC信任度。

数据位于 js/merchant-config.js 的 MERCHANT_DIALOGUE；展示与生命周期位于 js/merchant-dialogue.js。总览静态台词同时用于 safehouse-config.js 的军火商引言。后续可沿数据分组补充其他角色。

验证：node tools/test-merchant-dialogue.js，覆盖开发版及离线版、随机组归属与不连续重复、重绘保留、闲置计时及操作重置、弹窗抑制、成功／失败／取消、采购对白、窄屏及计时器清理。结果见 verification.json，预览见 greeting.png、procurement.png 和 mobile.png。商人UI与改枪结算回归通过，主流程402项通过、0失败。
