# 军用物资箱 Q

替代原通讯设备箱，保留标记Q、优质、1格实体、1.8秒搜索、噪声与原有电子/军事/情报偏好。

- 每箱抽取2–4次，其他优质容器仍为2–3次。
- 每次25%进入弹药池，75%沿用原物品池。
- 弹药池按优质容器等级曲线抽样：白10%、绿18%、蓝32%、紫30%、金10%。原红档0.5%只在弹药池并入金档。
- 三种口径等概率；5.56mm和9mm为10–20发/组，12号霰弹为4–8发/组。
- 弹药不去重，以免改变等级分布；其他物品保留原有去重逻辑。弹药仍不进入其他普通容器池。

图像由内置image_gen生成，原稿与实际提示词见manifest.json。交付 `assets/props/crate_military_supply.png`，48×48，透明边≥3px，二值alpha、16色。按1格绘制和碰撞；旧crate_comms为历史组件保留，Q统一读取新图。

生成整理：`node tools/prepare-military-supply.js`；构建与清单：`node build.js --assets-only`、`node gen-container-sheet.js`、`node gen-art-sheet.js`。不将正在编辑的地图草稿重新编译到游戏中；已有Q点位自动使用新名称和贴图，布局位置不变。

验证：`node tools/test-military-supply.js`，覆盖4万次弹药等级抽样、3000箱池占比、其他容器不受影响、像素规格、一格碰撞、编辑器选择/放置/撤销/保存重开、开发/离线与清单。另通过运行时283项回归、美术登记和地图模板检查。
