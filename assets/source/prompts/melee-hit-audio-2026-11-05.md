# 近战命中采样接入

原始文件由用户提供，保留在 `assets/audio/_source/近战命中音效/`。
作者与许可证尚无本地信息，登记为用户提供；不推测来源归属。

| 原始文件 | 运行时 ID | 用途 |
| --- | --- | --- |
| 547041小型剑或刀命中.wav | melee_hit_small | 旧式折叠刀 |
| 547038中型剑命中.wav | melee_hit_medium | M-9 制式战斗刀 |
| 547042大剑斩击命中.wav | melee_hit_large | 重型丛林砍刀 |
| 547036中型剑刺击.wav | melee_hit_stab | 预留刺刀等刺击武器 |

处理：使用 `tools/audio-slice.js`，起止 `0 10`（自动限制到源长度），
参数 `--trim=0.03 --rms=0.10 --in=2 --out=25`。
导出保持 44100Hz，转换为单声道 16bit PCM；已通过 `tools/audio-add.js` 登记。

武器定义的 `hitSfx` 指定命中采样；未指定时使用小刀采样。
挥砍风声仍在攻击开始播放，命中声在前摇结束、伤害实际结算时播放。
一刀命中多个目标仅播一次；挥空、被阻挡、取消攻击、死亡或零伤害不播放命中声。
`SFX.LOUD.meleeHit = 0.10`，播放速率随机 ±3%；现有削波保护保持生效。
重型砍刀仍保留原有未开放状态，不为音效测试改变获取规则。

后续刺刀只需在其近战武器定义中添加 `hitSfx: 'melee_hit_stab'`。
靶场音效试听面板提供四类声音的独立试听按钮。
