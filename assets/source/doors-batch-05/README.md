# 单格门洞几何试验

当前门体测试页的四种单格南北向门改用Canvas绘制：逻辑格内先铺地板，北、南两端各5px实心门框，框间22px作为通道。门框复用现有墙顶材质并补明暗边，不随状态淡化。

关闭状态按轮廓和材质区分：普通门为4px木色门轴和小把手；强化门为6px灰绿钢轴、铆钉和两端钢箍；上锁门在钢门基础上显示凸出的铜锁，解锁后不再显示；受阻门在受阻侧绘制细斜木闩，以像素阶梯构成斜度，带切角、木纹与两处小金属抱箍，正常侧不显示，踹开后永久移除本局木闩。开门时移除门轴/锁/木闩，保留门框。

整套结构固定在原32×32门格内，取消前次的上移半格、后层竖柱、下方柱与独立半格墙顶。相邻墙按原墙体规则显示；试验门不会改绘上方墙格。碰撞和视线沿用原门状态，关闭挡路/弹道/视线，开启可通行。没有新增或编辑PNG；上一批生成素材和记录仍保留在`doors-batch-04`。

门洞北侧的墙格保持连续铺满墙顶，不再朝门洞绘制南向立面；此规则仅作用于当前试验门上方。侧边收口、碰撞与门洞本身不变。

开门地面层：仅取东西向普通门`door.png`中间的门板（源区域x8、y7、宽16、高23），裁掉顶部与两侧门框。门板画在地板之上、物品/尸体/角色之下，不增加碰撞。门板靠轴一边直接对齐原竖门柱x=16的中心线，高度仍为北/南门框间的22px。默认向东展开，东侧不通而西侧可走时改向西，分别以门板左边/右边对齐同一门轴。不旋转或镜像贴图，不盖相邻墙体，角色正常绘制在门板上面。

强化/上锁门同样复用东西向`sdoor.png`的中间门板（x9、y7、宽13、高23），显示尺寸和门轴对齐与普通门相同。受阻门踹开后使用普通木门板。没有新增图片或改动物理判定。

入口：`doors.html`或`index.html#doors-test`。竖墙依次有受阻门（19,4）、普通门（19,6）、上锁门（19,11）和强化门（19,14）；搭建工具四种单格竖门均使用新方案。双格门仍沿用原表现，正式地图与编辑器未批量替换。

实现：`DoorVisual.sidePortal`绘制门框和门板，`DoorSystem.drawStudy`铺地板后调用；`Art.doorRect`将试验门固定在原格。共同的`sideStudy`测试标记保留，因此布局撤销/重做和重置仍兼容。

- `runtime.png`、`offline-runtime.png`：左关闭，右打开。
- 原有特殊门及搭建工具浏览器回归通过。
- `node tools/test-door-variants-browser.js`：四种关闭轮廓不同，横木方向/踹开移除、钥匙/铜锁移除、对应门板裁切复用及碰撞，开发/离线通过。`variants.png`和`offline-variants.png`按普通/强化/受阻/上锁排列，上关闭下开启；结果为`variants-quality.json`。
- 基础检查486通过、0失败；离线版已同步。
