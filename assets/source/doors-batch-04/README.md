# 南北向门四段结构试验

此批次保留为历史对照。当前测试页已切换至`../doors-batch-05/`的单格门洞几何方案。

本批次只生成一张普通门试验素材`assets/props/door_side_study.png`，32×48、硬alpha、16色；不替换已有门贴图。内置image_gen原稿保存在`sources/door_side_study.png`，实际提示词及追加要求在`assets/source/prompts/side-door-study-v4.json`。

从上到下的原生结构：

| 部件 | 像素区域 |
| --- | --- |
| 门框1 | x14–17，y0–3，宽4、高4 |
| 竖直细门柱 | x15–16，y4–27，宽2、高24 |
| 门框2 | x14–17，y28–31，宽4、高4 |
| 下方竖门框柱 | x14–17，y32–47，宽4、高16 |

主体共48px，即1.5格高。门框1下面另有一段宽4、高24的后层竖门框：复用下方粗柱材质，先以0.85不透明度绘制，再在前景叠加细门柱。打开后仅移除细门柱，门框1、门框2、后层门框和下方半格柱均保留；没有额外生成开门图片。

显示加粗：四段门体及后层门框统一以中心为轴横向放大1.5倍，局内门框/柱宽6px、细门宽3px；高度、位置、碰撞均不变。PNG原生宽度保留4px/2px，缩放仅作用于这张试验门。

绘制盒从门逻辑格上方16px开始，到本格底边结束。顶部另取墙顶贴图的上半部，放到上方一格的上半区域（相对门格y为−32至−16px）；上格下半部改绘地板作为门素材的背景。碰撞和交互仍使用原门格，没有扩展。

仅测试页使用：默认竖墙中段的`study-v`门（19,6）；搭建工具新放置的普通单格竖门自动使用本试验。强化门、受阻门、上锁门和双格侧门继续使用原方案。`sideStudy`仅存在于测试场景，不改正式地图或获取渠道。

整理工具：`node tools/prepare-side-door-study.js`。高分辨率原稿按四段裁切并归一化到规定区域，以保证门框和柱子的宽度一致；原稿边缘的光晕未进入运行时PNG。登记已同步`scene-assets.json`，角色为scene-component、footprint1×1、画布32×48。
