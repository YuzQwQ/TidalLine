# 近战武器

[正式图标及动画预览](index.html) · [原稿及实际提示词](manifest.json) · [浏览器与素材检查](quality.json) · [平衡探针结果](balance.json)

初版 3 把武器使用 18 份透明原稿；首批扩展另绘制 4 张图标和 4 张三向攻击图集，保存在 sources/。运行时合计 7 张 48×48 装备图标、27 张 64×64 单帧动画条。图标有至少 4px 安全边；动画按蓝灰色头部到脚底校准身体尺寸约 28px，脚底锚点固定为 (32,46)，武器举起不会让身体变小。采用最近邻采样、二值透明度，图标16色、人物32色。朝左镜像右向，不新增地图素材。

共用持刀待机三向各2帧，共用持刀行走三向各4帧；七种武器的攻击各三向4帧。前两帧对应前摇，后两帧对应命中及恢复，实际伤害不由动画触发。

折叠刀、战斗刀、三棱军刺、应急救援刀与工业撬棍由军火商出售。首次赠送刀具有绑定标记，不可出售，不再补发；重型丛林砍刀与廓尔喀弯刀不进商店，只在受雇回收员尸体背包和防水补给箱独立额外掉落。绑定字段随装备、仓库、背包、安全箱、遗落与存档保留。

整理素材：`node tools/prepare-melee-art.js`。逻辑测试：`node tools/test-melee.js`。素材与真实交互：`node tools/test-melee-browser.js`。平衡记录：`node tools/test-melee-balance.js`。

平衡探针使用120Hz、平坦开阔地、无护甲玩家和现有回响体AI，最多8秒；不代表对全部敌人、地形或Boss的平衡结论。当前记录显示：静止近战三种刀均受到反击；战斗刀后退攻击比站定少承受伤害；折叠刀后退和绕圈存在挥空；砍刀可一击击杀22HP回响体，三目标测试承受42HP损失。保留原定数值，没有扩大范围或新增减速。

开发版和离线版使用同一组PNG及代码。装备清单、Wiki从数据生成；纯代码/素材打包采用 `node build.js --assets-only` 保持当前地图快照。
