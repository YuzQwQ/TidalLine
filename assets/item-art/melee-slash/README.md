# 近战范围特效 · 第二版

[三张模板与七把武器实际绘制预览](index.html) · [实际提示词与原稿](manifest.json) · [验证报告](quality.json)

内置 image_gen 分别生成左粗→右细、右粗→左细两张通用挥砍模板，以及独立尖端刺击模板。原稿在 `sources/*-v2.png`，旧原稿仍保留。运行时挥砍模板为128×64，`melee_thrust.png`为64×128，32色、保留半透明、4px留边。提示词另存 `assets/source/prompts/melee-vfx-v2.json`。`node tools/prepare-melee-slash.js` 整理素材和总览页。

通用挥砍外缘由真实半径和扇角绘制：外圈固定，粗细向内渐变，按起手左右方向镜像。贴图提供灰色内侧残影，始终裁切到判定扇形。三棱军刺通过 `vfx: 'thrust'` 使用尖端轮廓和独立纹理，不画月牙。其他六把武器共享通用模板并自动适配大小和角度。

前摇显示淡范围提示；出手后清晰保持80ms，再淡出160ms，总计240ms。挥空也显示，取消和死亡后立即消失。前摇提示跟随瞄准，出手后锁定到命中方向。伤害时机、范围和碰撞规则保持原值；特效不产生飞行物或额外伤害。

这些是瞬态战斗特效，不是场景素材，无须登记为地图物块。构建：`node build.js --assets-only`。验收：`node tools/test-melee-slash.js`，覆盖每版56组武器/方向组合、边界裁切、粗细方向、军刺模板选择、前摇/峰值/淡出/取消和开发/离线一致性。`previews/`是从真实游戏绘制函数导出的预览；总览页同时检查320/390px布局。
