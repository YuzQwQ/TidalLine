# 门图重绘：匹配当前高墙

[八图及墙门组合预览](index.html) · [实际提示词与原稿](manifest.json) · [验证记录](quality.json)

普通门与避难门各有正向/侧向、关闭/打开，共8张。使用内置image_gen分别生成四张关闭图，再以各自关闭图编辑打开状态。普通侧门打开图曾保留错误的长杆，单独修复后采用；未采用稿也保存在sources/。

沿用当前浅石色墙顶和灰绿墙面，普通门为旧灰绿木板，加固门为深灰绿钢板。交付`assets/props/door*.png`、`sdoor*.png`，原生32×48、透明边≥2px、16色、二值alpha；不旋转正面图冒充侧面图。旧门图备份在previous/。

整理按alpha≥200裁切并去除原稿外围柔边，最近邻缩放、少色量化；正向主体放入28×44范围，侧向组件分别校准至14×44或18×44，底边统一y45。打开状态中央通路透明，侧门只保留南北端头与北侧收拢门扇。

`Art.doorRect`保持墙脚坐标，向北抬高16px；横向多格门扩展宽度，纵向多格门总高为格数×32＋16。门框按已探索格裁切，开关状态、碰撞、交互规则保持原样。编辑器的门图也采用相同高度与跨度。

重新整理与生成页面：

```sh
node tools/prepare-door-redraw.js
node tools/gen-door-redraw-gallery.js
node build.js --assets-only
node gen-art-sheet.js
node tools/test-door-redraw.js
```

专项检查覆盖8张规格/透明通路、全部方向与开关选图、单/双格锚点、门开关碰撞、离线像素级迷雾裁切、编辑器撤销与保存重开、320/390px预览。开发版file://受Canvas跨域限制，不读取画布像素；同一裁切代码在离线版进行像素断言。另通过283项运行时回归和美术登记检查。

素材目录已登记原有8个稳定ID，无需迁移地图门记录。本次离线构建沿用已编译地图快照，不重编译正在编辑的地图布局。
